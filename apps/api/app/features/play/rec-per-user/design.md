# 골든벨·이게 뭐게 가비 추천 사용자별 보이기 설계 (승인 2026-11-20)

브랜치 `fix/hellobk-play-rec-user`(`origin/release/1.3` `5ec3ec88` 기준, 사용자 지정). PR 제목 `feat(play): 골든벨 이게뭐게 가비추천 사용자마다 다르게 처리`.

## 왜
가족이 같은 추천 카드를 봐서 한 사람이 낸 문제의 답을 다른 가족이 미리 본다. 찰칵 탐정단처럼 사람마다 다른 구성을 보여 준다.

## 사용자 결정
- 섞는 기준은 사용자 id와 날짜(가족 id만으로는 모두 같은 결과).
- 보여 주는 개수는 후보 수의 절반 올림(1→1, 2→1, 3→2, 4→2, 5→3, 6→3, 7→4). 1~2개 겹침은 허용, 후보가 1~2개뿐이면 같은 문제를 보는 것은 어쩔 수 없음.
- 이게 뭐게 그림 생성은 5개 그대로. 저장된 그림은 보관 기간 제한 없이 계속 쓴다(단어당 3종 상한은 유지).
- 한 PR, 커밋 4개:
  1. `feat(play): 추천문제 공통함수`
  2. `feat(play): 골든벨 가비 추천 사람마다 다르게`
  3. `feat(play): 이게뭐게 가비 추천 사람마다 다르게`
  4. `feat(play): 이게뭐게 저장된 그림 보관 기간 제거`
- 로컬 테스터용 미추적 파일 3개(`bomb_dev_skip.py`, `scripts/dev_bomb_bot.py`, `scripts/seed_play_dev.py`)는 커밋에서 제외.

## 방식 (확정)
생성·캐시(가족 단위, 자정까지)는 그대로 두고, 응답 직전에 사용자별로 고른다. 사용자별 생성은 비용이 몇 배라 제외.

- 공통 함수(새 파일 `play/rec_pick.py`, 에이전트 판단): `pick_for_user(items, group_id, user_id, today)`. 항목 `id` 를 `가족|사용자|날짜|id` 해시로 정렬해 앞에서 절반 올림만 고르고 원래 순서로 돌려준다(후보가 늘거나 줄어도 나머지 상대 순서 유지).
- 골든벨 `quiz_rec.recommend`: 이미 낸 문제를 숨긴 뒤 마지막에 적용.
- 이게 뭐게 `draw_rec.recommend`: 반환 지점 3곳(정상·일부만·한도 소진 때 저장소 그림) 모두 적용.
- 보관 기간 제거 `draw_stock`: `STOCK_DAYS` 필터와 `add_variant` 의 만료 삭제 제거, `STOCK_MAX=3` 유지.

앱 화면, DB 마이그레이션, 찰칵 코드, 사용자별 생성.
