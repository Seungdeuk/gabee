# 가비 운영 관리 웹 (apps/ops-admin)

서버·시스템이 잘 도는지 보는 운영자용 화면. 순수 HTML + JavaScript (빌드·npm·외부 스크립트·외부 글꼴 없음, TypeScript 금지).
요구사항: `docs/requirements/ops-admin.md`. 서비스 관리자(사용자·가족) 화면과는 별개다.

## 로컬에서 보기
```bash
cd apps/ops-admin
python -m http.server 5601
# 브라우저: http://127.0.0.1:5601
```
(이 PC 는 기본 `python` 이 스토어 껍데기라서 `apps/api/.venv/Scripts/python.exe` 를 쓴다.)

## 샘플 모드 범위 (로컬 전용)
- 참고 시안(Gabee 운영 관리자)의 구성을 옮겼다: 왼쪽 메뉴 5개(운영 대시보드·인프라·API 상태·로그/오류·배포/DB) + 상단 헤더(새로고침·알림) + 요약 카드 + SVG 차트 + 표(정렬·필터·페이지) + 상세 모달.
- 샘플 모드에서 **모든 값은 `js/app.js` 안의 가짜(샘플) 데이터**다. 위쪽 "샘플 데이터" 띠와 "상태 미리보기"(정상/로딩/오류/데이터 없음)로 각 상태를 볼 수 있다.
- 처리 상태·조치 내용 변경은 브라우저 메모리 안에서만 바뀌고 저장되지 않는다.
- AI 운영 Agent 화면은 아직 없다(이후 단계).
- `js/config.js`, `js/api.js`, `js/auth.js` 는 서버 연결 모드(아래)의 설정·호출·로그인 코드다. 샘플 모드는 이 코드를 쓰지 않는다.

## 샘플 로그인
- 실제 인증이 아니다. `js/sample-account.js`(커밋 제외)에 계정을 두고, `sample-account.example.js`를 복사해 만든다. 서버 모드는 JWT 로그인을 쓰고, 이 파일은 로컬 샘플 모드에서만 쓴다(배포본에는 없다).
- 로그인 상태는 메모리에만 있어 새로고침하면 다시 로그인한다. 5회 실패 시 30초 잠금(화면 연출용, 보안 아님).

## 원칙
- 토큰은 메모리에만 둔다(서버 연결 후, 새로고침하면 다시 로그인).
- 사용자·가족 id, 대화 내용은 화면에 보이지 않는다. 샘플에도 실제 값을 쓰지 않는다.
- 서버 값을 화면에 넣을 때는 반드시 `esc()` 로 감싼다(현재 코드는 문자열 조립 방식이라 이 규칙이 필수다).
- 스타일 속성(style="...")을 쓰므로 CSP 의 style-src 에 `'unsafe-inline'` 이 있다. 스크립트는 같은 출처 파일만 허용한다.

## 수동 확인 체크리스트
- [ ] 5개 메뉴 이동, 새로고침 버튼(로딩 후 복귀), 알림 벨(읽음 처리)
- [ ] 상태 미리보기 4가지(정상/로딩/오류/데이터 없음)
- [ ] 로그 필터·정렬·페이지, 상세 모달(처리 상태 변경, 조치 내용 저장, Trace ID 복사)
- [ ] 폭 900px 이하에서 메뉴가 햄버거로 접힘, 표는 가로 스크롤
- [ ] 다크 모드(OS 설정)

## 서버 연결 모드 (W2)
- `js/config.js` 가 모드를 정한다. **기본은 서버 모드**이고, 샘플 모드는 로컬 `js/local-config.js` 가 `mode: "sample"` 을 명시하고 `js/sample-account.js` 에 계정이 있을 때만 켜진다(두 파일 모두 커밋 제외, 배포본에 없음).
- 로컬에서 서버에 붙이려면 `local-config.example.js` 를 `local-config.js` 로 복사한다(커밋 제외). 기본 서버 주소는 `https://api.gabee.cloud`.
- 로그인은 `/family-group/auth/login` → 곧바로 `/admin/ops/summary` 를 불러 운영자 여부를 확인한다. 403 이면 토큰을 버리고 "권한 없음" 만 알려 준다. 토큰은 메모리에만 있다.
- 서버 모드 대시보드는 A 상태 바(정상/주의/오류, 기준: 5xx 비율 5% 이상(요청 20건 이상)이면 오류, 5xx·새 오류가 있거나 1% 이상이면 주의) · B 지표 카드 5개 · C 요청 추이 · D 지금 확인할 오류(클릭 시 상세) · E 문제 경로 TOP5(요청 5건 이상) · F DB·마이그레이션·수집 상태와 GCP 콘솔 바로가기이다. "5xx 증가"는 이전 기간 조회가 불가능해 같은 기간의 전반 대비 후반으로 비교하며, 화면은 약 60초마다 갱신한다. **서버 모드는 사이드 메뉴 없이 이 대시보드 한 페이지만 쓴다**(오류 "전체 보기"와 "전체 경로 표"는 같은 화면에서 펼친다). 로컬 설정 변수는 `GABEE_LOCAL`(예전 `GABI_LOCAL` 도 읽는다).
- 서버 모드에서 실제 데이터가 있는 화면은 **대시보드(요청 지표)**, **API 상태(경로별 집계)**, **인프라(`/admin/ops/infra`)**, **로그/오류(`/admin/ops/errors`)** 이다. 인프라·오류 조회가 실패하거나(서버에 아직 배포되지 않아 404 등) 수집이 꺼져 있으면 그 이유를 보여 주고 다른 화면은 그대로 동작한다. 배포/DB 는 샘플을 섞지 않고 "아직 서버와 연결되지 않았습니다" 로 표시한다. 응답 시간은 평균·최대만 있고 p95 는 없다.
- CSP: `index.html` 의 meta 는 로컬 개발 주소와 `https://api.gabee.cloud` 만 허용한다. 배포본은 Cloudflare Pages 가 `_headers` 의 더 좁은 CSP(`connect-src 'self' https://api.gabee.cloud`, `frame-ancestors 'none'`)를 함께 적용한다. 남은 완화: `style-src 'unsafe-inline'`.
  - **확정 18차로 호스팅이 Cloud Run 같은 서비스로 바뀌었다.** 위 `_headers`(Pages 전용)와 `api.gabee.cloud` 기준 `connect-src` 는 같은 출처가 되면 달라질 수 있다(미검증). 배포 안내는 방식이 정해질 때까지 미정이다.
- 서버 CORS 는 서버의 `CORS_ORIGINS` 환경변수로 좁힌다(코드 변경 없음). 값 예: `https://ops.gabee.cloud`. 이 화면을 쓰는 브라우저 출처만 넣는다. (확정 18차로 같은 출처가 되면 CORS 좁히기가 달라질 수 있다 — 미검증, 배포 방식 확정 뒤 다시 본다.)
