# 구현 현황: AI 채팅 웹 검색

- 상태: 구현 완료, 기본 꺼짐(`WEB_SEARCH_ENABLED`). 폰 화면 확인은 아직.
- 요구사항: [docs/requirements/ai_assistant-web-search.md](../requirements/ai_assistant-web-search.md)

## 동작

- AI 채팅 탭(`audience=me`)의 메인 모델에만 Anthropic 서버 도구 `web_search_20250305` 를 준다. 가족방 `@가비`, 탭 에이전트, `/ai-assistant/knowledge/ask` 에는 주지 않는다.
- 검색할지는 Claude 가 판단하고, 기준은 `rag_chat.WEB_NOTE` 에 있다. 서버 도구라 `_handle_calls` 로 오지 않는다.
- 응답 블록은 어댑터가 원본 그대로 보존해 다음 요청에 돌려보낸다(`encrypted_content` 포함). 앞 대화에는 글만 남고 검색 결과는 다음 질문으로 이어지지 않는다.
- `pause_turn` 은 `tool_graph` 가 `MAX_STEPS` 안에서 이어서 부른다.
- 응답의 `web_sources` 는 답이 인용한 페이지만 담는다(같은 주소 하나로, http(s) 만, 최대 5개). 앱은 답 아래에 "웹에서 찾았어요" 카드를 펼쳐 보여 주고, 제목을 누르면 브라우저로 연다.
- 검색을 쓰는 요청은 `max_tokens` 가 4096 이다. 1024 로는 실제 호출에서 답을 쓰기 전에 끊겨 빈 답이 됐다.

## 실제 호출 확인 (Haiku 5.5, 2026-11-09)

| 질문 | 쓴 도구 | 검색 | 입력·출력 토큰 |
|---|---|---|---|
| 오늘 서울 날씨 어때? | web_search | 1번 | 21,062 / 1,101 |
| 올려 둔 관리비 고지서 이번 달 얼마야? | search_knowledge 2번 | 0번 | 측정 안 함 |
| 3 더하기 4는 얼마야? | 없음 | 0번 | 측정 안 함 |
| 관리비 고지서 찾고, 전기요금 아끼는 법도 웹에서 찾아줘 | search_knowledge 2번 + web_search | 1번 | 호출 3번 합계 45,812 / 1,740 |

질문 네 개를 한 번씩 돌린 확인이라 판단 정확도를 잰 값은 아니다. 우리 도구는 빈 결과를 돌려주게 했고, DB·앱은 거치지 않았다.

## 한계

- 검색어에 개인정보를 넣지 말라는 것은 프롬프트 지시라 코드로 보장되지 않는다.
- 출처 품질을 고르지 않는다. 날씨처럼 공식 사이트가 있는 질문에도 블로그나 해외 사이트가 나올 수 있다. 시험에서는 영어 검색어가 쓰이기도 했다.
- 검색 횟수를 `ai_usage_logs` 와 하루 한도에 따로 세지 않는다.
- 웹 검색을 조직 설정에서 끄면 요청이 400 으로 실패해 503 `llm_failed` 가 된다.
- 처리방침·Play 데이터 안전 양식 문구는 아직 없다.
