## 구현된 것
앱(`apps/mobile/src/features/schedule/`), mock 데이터 기준. 서버 연동 없음.
- `constants.js`: 형태·체크 라벨, 막대·주제·점 색(임시 값)
- `model.js`: 항목 타입(JSDoc), 정렬, 필터(누구는 "또는", 줄끼리 "그리고", "부모님" 칩 포함), 누구 처리("부모님" 합치기, 공백은 만든 사람)
- `mock.js`, `store.js`: 오늘 기준 샘플과 메모리 저장소(추가·수정·삭제·체크)
- `utils/date.js`: 주(월~일 / 일~토)·달 계산, 한글 날짜·시간 표기
- `components/`: EventCard(compact/detailed), CheckMark, FormTag, FilterChip, SectionHeader, WeekStrip, BottomSheet
- 메인 화면(`screens/ScheduleScreen.js`, 와이어프레임 v1.2 기준): 헤더 + 주간 스트립(월~일, 일정 있는 날 점), 오늘·내일 카드(체크 수 표시·체크 동작), 함께하기 한 줄, 먼저 권해드려요, 채팅 입력창. + 아이콘과 주간 스트립 날짜는 달력으로 이동(그 날짜 선택)
- 먼저 권해드려요(`suggestions.js`): 약속 확인 카드("오늘 약속을 모두 확인했어요"를 남김), 할 일 확인 카드(오늘 할 일 + 에이전트가 유추한 챙길 것, "오늘 할 일을 모두 확인했어요"를 남김), 추가 제안 카드. 나중에·새로고침 동작 포함. 챙길 것·추가 제안 문장은 임시
- 달력 화면(`screens/CalendarScreen.js`, 와이어프레임 v1.1 기준): [달력|목록] 전환, 누구·주제 필터 칩 두 줄(켜고 끄기), 월 달력(점 최대 3개·약속 먼저, 달 이동, 접기·펴기 버튼), 선택한 날짜 목록과 [모두|약속|할 일]. `calendar.js`(점·필터·날짜별 항목·시간 구분), `components/MonthCalendar·FilterRows·SegmentedControl·AddButton`
- 목록 모드(`components/ListMode.js`): 오늘(비어도 표시, 확인·완료 수 표시) → 다가오는 것(월 구분선, 숫자 없음) → 지난 것(기본 접힘, 최근 3개 + "이전 기록 N개 더 보기", 흐리게·체크 없음, 없으면 숨김). 구역 제목을 눌러 접고 펴며, 필터를 하나라도 켜면 자동으로 목록, 모두 해제하면 달력으로 돌아옴. 달력 모드에서 목록이 길면 아래로 스크롤할 때 달력이 접히고 맨 위로 오면 펴짐
- 등록 화면(`screens/RegisterScreen.js`, 와이어프레임 v1.2 기준): 형태 [약속|할 일] 선택(입력 항목은 같음), 제목·날짜 필수, 누구·주제·공유 칩, 시간·장소·메모 선택, 저장하면 mock 저장소에 추가하고 진입했던 화면으로 복귀, 제목 옆 ‹·취소. 날짜 시트(`components/DateSheet.js`: 오늘·내일·토·일 빠른 선택 + 월 달력 + "직접 입력"). 직접 입력은 YYYY-MM-DD 한 칸이고 연도까지 받으며, 연·월·일 영역을 터치하면 영역이 블록으로 선택돼 숫자를 치면 그 영역이 새로 채워지고(월에서 9 → 09처럼 첫 숫자가 크면 0을 붙여 다음 영역으로 자동 이동, 범위 밖 숫자는 무시) 올바른 날짜가 되면 아래 달력이 그 날짜로 이동하고, 반대로 달력에서 날짜·달을 고르면 입력 칸의 숫자도 바뀐다(양방향). 확인 버튼은 없고 "빠르게 고르기"를 누르면 입력 칸이 사라지고 오늘·내일·토요일·일요일 줄로 돌아간다. 시간 시트(`components/TimeSheet.js`·`TimeWheel.js`): 왼쪽에 시작·끝을 한 줄씩(라벨, 오전|오후 두 글자 버튼, 작은 HH:MM 입력 칸), 오른쪽에 시(0~23)·분을 돌려 고르는 24시간 시계(분은 5분 단위). 화면은 모두 24시간 표기이고 입력 칸과 시계는 같은 값을 공유해 어느 쪽에서 바꿔도 바로 반영된다. 시·분 영역을 터치하면 블록으로 선택되고, 오전|오후는 입력할 때의 변환 보조다(오후를 골라 두고 11을 치면 23:00, 13~23시는 쓴 그대로). 버튼을 누르면 지금 시각이 12시간 옮겨진다. 종일을 켜면 아래는 흐려지고 반응하지 않으며, 끝은 시작 + 1시간으로 자동 채움. "시간 없음"은 시간 라벨 옆 글자 버튼. 입력 칸은 `components/BlockInput.js`, 계산은 `utils/time.js`. 등록 화면 날짜 칸에는 연도를 함께 보이고, 확정된 시간은 24시간 옆에 오전·오후 표기를 괄호로 덧붙인다(14:00 – 16:00 (오후 2:00 – 오후 4:00)). 등록 화면 날짜 칸에는 연도를 함께 보인다(2026년 10월 24일 토요일). 진입: 메인 "약속 · 할 일 추가하기", 달력 날짜 옆 +, 목록 오늘 옆 +, 먼저 권해드려요의 "추가"·"아직이요"(미리 채움 + 안내 문구)
- 상세 화면(`screens/DetailScreen.js`, 와이어프레임 v1.2 기준): 카드를 누르면 열림(메인·달력·목록). 형태 배지, 주제(있을 때만), 제목(누구 이름표), "내가 만들었어요"/"OO가 공유했어요", 정보 카드(날짜(연도 포함)·시간·장소·누구·공유·메모, 값 없으면 줄 숨김, 누구는 일반 글자), 확인·완료 줄(눌러서 켜고 끄기, 목록 카드 체크와 같이 움직임). 수정·삭제는 만든 사람에게만 보이고, 공유받은 사람은 보기와 확인·완료만 가능. 수정은 등록 화면을 현재 값으로 채워 열고(제목줄 "수정", 형태 변경 가능) 저장하면 상세로 돌아옴. 삭제는 화면 가운데 확인 팝업(`components/ConfirmDialog.js`, 공유한 사람 안내 포함)
- 라우트: `app/(tabs)/schedule/`(`index.js` 메인, `calendar.js` 달력, `register.js` 등록·수정, `detail.js` 상세, `_layout.js` 스택). 달력에서도 하단 탭 바가 보이고, 제목 왼쪽 ‹ 버튼으로 일정 메인에 돌아감(웹에서 달력 주소를 직접 열었을 때도 일정 메인으로 감)
- `npm run lint` 통과

## 남은 것
- 등록: 시계는 웹에서 모양과 누르기만 확인했고, 손가락으로 밀어 고르는 느낌은 폰에서 확인 필요
- 달력: "+ 누구"·"+ 주제" 추가와 칩을 꾹 눌러 이름·색 변경·삭제(칩 관리)
- 메인에서 이동 연결: 함께하기·같이하기(같이), 채팅 입력(채팅)
- 화면: 같이, 채팅
- 상세: 확인·완료 상태를 사람별로 둘지, 공유받은 사람의 수정 권한, 삭제 후 되돌리기, 반복 일정의 수정·삭제 범위(미정)
- 서버 연동(서버 `schedule` 기능 확장 합의 후 `api.js`)
- 임시 색을 디자인 토큰으로 확정
