## 구현된 것
앱(`apps/mobile/src/features/schedule/`), mock 데이터 기준. 서버 연동 없음.
- `constants.js`: 형태·체크 라벨, 막대·주제·점 색(임시 값)
- `model.js`: 항목 타입(JSDoc), 정렬, 필터(누구는 "또는", 줄끼리 "그리고", "부모님" 칩 포함), 누구 처리("부모님" 합치기, 공백은 만든 사람)
- `mock.js`, `store.js`: 오늘 기준 샘플과 메모리 저장소(추가·수정·삭제·체크)
- `utils/date.js`: 주(월~일 / 일~토)·달 계산, 한글 날짜·시간 표기
- `components/`: EventCard(compact/detailed), CheckMark, FormTag, FilterChip, SectionHeader, WeekStrip, BottomSheet
- 메인 화면(`screens/ScheduleScreen.js`, 와이어프레임 v1.2 기준): 헤더 + 주간 스트립(월~일, 일정 있는 날 점), 오늘·내일 카드(체크 수 표시·체크 동작), 함께하기 한 줄, 먼저 권해드려요, 채팅 입력창. + 아이콘과 주간 스트립 날짜는 달력으로 이동(그 날짜 선택)
- 먼저 권해드려요(`suggestions.js`): 약속 확인 카드("오늘 약속을 모두 확인했어요"를 남김), 할 일 확인 카드(오늘 할 일 + 에이전트가 유추한 챙길 것, "오늘 할 일을 모두 확인했어요"를 남김), 추가 제안 카드. 나중에·새로고침 동작 포함. 챙길 것·추가 제안 문장은 임시
- 달력 화면(`screens/CalendarScreen.js`, 와이어프레임 v1.1 기준): [달력|목록] 전환, 누구·주제 필터 칩 두 줄(켜고 끄기), 월 달력(점 최대 3개·약속 먼저, 달 이동, 접기·펴기 버튼), 선택한 날짜 목록과 [모두|약속|할 일]. `calendar.js`(점·필터·날짜별 항목·시간 구분), `components/MonthCalendar·FilterRows·SegmentedControl·AddButton`
- 목록 모드(`components/ListMode.js`): 오늘(비어도 표시, 확인·완료 수 표시) → 다가오는 것(월 구분선, 숫자 없음) → 지난 것(기본 접힘, 최근 3개 + "이전 기록 N개 더 보기", 흐리게·체크 없음, 없으면 숨김). 구역 제목을 눌러 접고 펴며, 필터를 하나라도 켜면 자동으로 목록, 모두 해제하면 달력으로 돌아옴. 달력 모드에서 목록이 길면 아래로 스크롤할 때 달력이 접히고 맨 위로 오면 펴짐
- 등록 화면 ①(`screens/RegisterScreen.js`, 와이어프레임 v1.2 기준): 형태 [약속|할 일] 선택(입력 항목은 같음), 제목·날짜 필수, 누구·주제·공유 칩, 시간·장소·메모 선택, 저장하면 mock 저장소에 추가하고 진입했던 화면으로 복귀, 제목 옆 ‹·취소. 날짜 시트(`components/DateSheet.js`: 오늘·내일·토·일 빠른 선택 + 월 달력). 진입: 메인 "약속 · 할 일 추가하기", 달력 날짜 옆 +, 목록 오늘 옆 +, 먼저 권해드려요의 "추가"·"아직이요"(미리 채움 + 안내 문구)
- 라우트: `app/(tabs)/schedule/`(`index.js` 메인, `calendar.js` 달력, `_layout.js` 스택). 달력에서도 하단 탭 바가 보이고, 제목 왼쪽 ‹ 버튼으로 일정 메인에 돌아감(웹에서 달력 주소를 직접 열었을 때도 일정 메인으로 감)
- `npm run lint` 통과
