# 구현 현황: 대화 내용 전달

- 상태: 구현 완료. 폰 확인은 아직.
- 요구사항: [docs/requirements/ai_assistant-share.md](../requirements/ai_assistant-share.md)

## 구조

- 서버: `ai_assistant/sharing.py`(받는 사람 찾기, 카드 만들기, 실행), 메인 채팅 도구 `prepare_share`, `POST /ai-assistant/agent/confirm`, 보내기는 `family_chat/assistant.share_as_user`(일반 메시지와 같은 길이라 저장·푸시가 같다).
- 카드: 지갑 제안과 같은 토큰 방식(`shared/llm/proposals`, 서명·10분·한 번만). 토큰에 글이 들어 있어 확인 요청의 길이 제한만 따로 둔다(`ShareConfirmIn`).
- 앱: 기존 확인 카드(`mapProposals`)에 `ai-assistant` 탭을 더했다. 제목은 "가족에게 전달하기".

## 실제 호출 확인 (Haiku 5.5, 2026-11-09, 임시 SQLite 의 가짜 가족)

| 말 | 결과 |
|---|---|
| 내가 좋아하는 롤 팀은 T1이야. 기억해 줘 | `remember` 저장 |
| 내가 좋아하는 롤 팀이 어디라고 했지? | 기억을 써서 T1 이라고 답함 |
| 오늘 날씨 좋네 | 저장 안 함 |
| 아까 식당 추천 내용 엄마한테도 알려줘 (앞 대화에 회사 고민 포함) | `prepare_share` 카드, 식당 내용만 담고 고민은 뺌, 받는 사람 김엄마(엄마) |
| 그거 알려줘 | 추측하지 않고 어떤 내용인지 되물음 |
| T1 기억은 잊어줘 | `forget` 삭제 |

한 번씩 돌린 확인이라 정확도를 잰 값은 아니다. 호칭으로 "회원님"이 한 번 나왔다(말투 지침은 호칭을 쓰지 말라고 되어 있다).

## 한계

- 요약에 다른 얘기를 넣지 않는 것은 프롬프트 지시다. 카드에서 사람이 확인한다.
- 가족 관계는 본인이 고른 값이라 사람에 따라 다르게 불러도 별명이 없으면 그대로 찾는다. 카드에 실제 이름이 보인다.
- 카드 안에서 바로 고칠 수 없다. 채팅으로 다시 말하면 새 카드가 나온다.
- 앞 대화 10개 밖의 내용은 볼 수 없어 되묻는다.
