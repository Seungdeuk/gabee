  - 확인된 사실: 일정 Agent 의 가족방 채널은 일정은 공유된 것만 읽지만(`reader.py:66`), 부탁 목록은 `request_flow.load(..., detail=False)`(`handler.py:242-245`)로 받는 사람·수락 현황만 빼고 **제목은 그대로** 모델에 준다. 이번 위반은 채점기 오탐이 아니라 **실제 권한 범위 밖 제목 노출 경로**로 보인다(공개 대화의 "쌀도 사 오자"와 문구가 다르고 부탁은 공개 유래 표식이 없다). 운영 영향: 가족방 @가비 질문에서 일정 Agent 가 불리면 두 사람 사이의 부탁 제목이 방 전체에 보일 수 있다(일정 담당과 협의 필요).
- **r0(일반 실패)**: 메인은 지침대로 소통 Agent 만 불렀지만 질문을 "가족 공동 할 일 목록에 있는 장보기 목록"으로 바꿔 넘겼고, 소통 Agent 는 `list_todos` 만 써 대화 속 목록을 찾지 않았다(`missing_tool`). 가설: 새 지침의 "방에서 목록을 말하지 않은 할 일·목록 질문은 가족 공동 목록을 가리킨 것으로 본다" 문장이 대화 속 목록 질문을 공동 할 일로 좁혔을 수 있다(기준선 3/3, b669a036 3/3 에서 하락). 단정하지 않는다.
