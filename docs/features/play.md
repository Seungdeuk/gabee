# 구현 현황: play (가족 놀이터)

- 상태: 진행 중 (골든벨·이게 뭐게·찰칵! 탐정단 서버 API 완료, 문장 폭탄방 API와 앱 연결은 남음)
- 요구사항: 위키 `family-playground`(규칙), `family-playground-db`(테이블)
- 테이블: `docs/contracts/db.md` 의 `play_*` 9개 (Alembic `5d2a8f1c9b37`)

## 구현된 것

### 공통

- 비동기 놀이 3종(골든벨 1·이게 뭐게 2·찰칵! 탐정단 3)은 `play_items` 한 줄에서 시작한다. 받는 사람을 비우면 가족 모두(낸 사람 제외). 만든 시각 + 24시간 뒤에 닫히고, 받는 사람이 모두 끝내면 그 순간 닫힌다.
- **마감은 조회·제출 때 계산한다**(배치 없음). 현황판·문제·답 보내기·순위를 부를 때 닫힌 놀이를 정산하고, 낸 사람 점수(`reason=3`)는 점수 줄이 이미 있는지 보고 문제 줄을 잠가서 한 번만 넣는다.
- 점수: 참여 +10(항상), 정답 +20(골든벨은 세트 20점을 맞힌 비율로 반올림), 힌트·줄여 보기 −5씩(틀려도 깎고, 최대 2번이라 총점은 0 아래로 내려가지 않음), 문제 낸 사람 +20(닫힐 때, 받는 사람 중 한 명이라도 참여해야, 한 명이 한국 시간 하루 3건까지, 낸 순서대로 셈).
- 정답·한마디는 낸 사람, 이미 끝낸 사람, 닫힌 뒤에만 보인다. 가족 모두의 답은 닫힌 뒤에만, 푼 순서로 보인다.
- 푸시 알림은 아직 없다.

### 엔드포인트

| 경로 | 설명 |
|---|---|
| `POST /play/quiz` | 골든벨 세트(1~5문항) 내기 |
| `POST /play/draws` | 이게 뭐게 내기 (multipart: `file` PNG ≤2MB, `answer`, `alt_answers`, `hint2`, `player_ids`) |
| `POST /play/photos` | 탐정단 내기 (multipart: `file` JPEG/PNG/WebP ≤8MB, `source`, `zoom`, `box_x`, `box_y`, `question`, `options`, `answer_index`, `comment`, `player_ids`) |
| `GET /play/board` | 받은(할 차례·참여했어요·지난 결과 3일)과 보낸(내가 낸 문제·지난 결과) |
| `GET /play/items/{id}` | 문제 한 건 |
| `GET /play/items/{id}/image` | 그림(PNG) 또는 사진(JPEG). 로그인 필요, 같은 가족만 |
| `POST /play/items/{id}/answers` | 골든벨은 문항 수만큼 한 번에, 탐정단은 `quiz_no` 0 한 건 |
| `POST /play/items/{id}/hints` | 이게 뭐게 힌트 열기 / 탐정단 조금 줄여 보기 (최대 2번, 이게 뭐게는 힌트 2가 없으면 1번) |
| `POST /play/items/{id}/tries` | 이게 뭐게 정답 쓰기 (최대 10번) |
| `GET /play/ranking?period=week\|month\|all` | 순위 (이번 주는 월요일 시작) |

### 이게 뭐게

- 정답 비교는 공백을 없애고 대소문자를 무시하며 `alt_answers`(이것도 정답)도 맞다. 힌트 1은 정답 글자 수("3글자")를 서버가 만들고 힌트 2는 낸 사람이 쓴 한 줄이다.
- 시도마다 `play_answers` 한 줄(`try_no` 1~10, `quiz_no` 0). 힌트를 연 횟수는 `try_no` 0 줄 하나의 `hints_used` 에 두고, 이 줄은 참여로 세지 않는다.
- 맞히거나 10번을 다 쓰면 끝나서 참여 +10(맞히면 +20 추가). **틀려도 감점은 없다.** 끝내지 못한 채 닫히면 답을 한 번이라도 제출한 사람은 닫힐 때 참여 +10(쓴 힌트만큼 −5)을 받고 지난 결과에 남는다. 답을 제출하지 않고 힌트만 연 사람은 참여가 아니라 점수도 감점도 없다.
- 끝나기 전에는 현황판의 "내가 참여했어요"로 옮겨지지 않는다.

### 찰칵! 탐정단

- 선택식만. 정답은 보기 순서의 비트 글자(`"0100"`). 확대 배율은 4·6·8·16·32, 확대 창 가운데 위치 `box_x`/`box_y`(0~1).
- 푸는 중인 사람에게는 **원본이 아니라 확대한 조각만** `image` 로 나간다. 조금 줄여 보기를 쓸 때마다 배율이 절반이 된다(최소 1배). 낸 사람·답을 보낸 사람·닫힌 뒤에는 원본 전체가 나간다. `image_url` 의 `v=` 값이 줄여 보기 횟수와 공개 여부에 따라 달라져서 오래된 사진이 캐시에 남지 않는다.

### 파일 저장

- 서버 디스크 `settings.data_dir` 아래 `play/drawings/<가족id>/<놀이id>.png`, `play/photos/<가족id>/<놀이id>.jpg`. DB에는 상대 경로만 둔다. 파일 이름은 서버가 만든 id 로만 짓고, 읽을 때도 DB 경로가 그 형태인지 확인한다.
- 올린 이미지는 서버가 다시 만들어 저장한다(EXIF·GPS 제거, 긴 변 1600px 이하, 압축 폭탄 방어). 파일 쓰기와 DB 확정 중 하나가 실패하면 반쪽이 남지 않게 정리한다.
- 운영 배포용 파일 저장소는 아직 정하지 않았다(Cloud Run은 컨테이너 파일이 재시작 때 사라진다).
