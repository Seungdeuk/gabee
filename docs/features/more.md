# 구현 현황: 마이 페이지 (more)

서버 기능은 없다(앱 화면만). 요구사항 문서도 없어 사용자(정산·돌봄 담당)가 구성을 직접 정했다.

## 구현된 것 (`apps/mobile/src/features/more`)
- **하단 마지막 탭 "마이"**(`app/(tabs)/my.js`): `MoreScreen` 을 연결한다. 제목은 "마이페이지". 탭은 AI 채팅·소통·일정·돌봄·마이 5개다.
- 구성(위에서 아래): 제목 줄(오른쪽 위 톱니 환경설정 아이콘 하나, 글자·바탕 없음, 누르면 환경설정 화면 `/settings`) → **프로필 카드**(`ProfileCard`: 이름, 가족 이름 · 역할, "내 정보 수정", 오른쪽 화살표, 카드를 누르면 `/family-profile`, 로그인 전에는 로그인 안내) → **한 줄 바로가기 4칸**(`ShortcutGrid`: AI 리포트·타임라인·구독 관리(→ `/subscription`)·가족 초대(→ `/family-invite`, 관리자에게 대기 중인 가입 요청 수가 아이콘 오른쪽 위에 숫자로 붙는다), 아이콘 아래 이름만 보임) → **묶음 목록**(`MenuList`: "가족 및 AI 서비스" = 우리 가족·가족 위치 확인·가비 AI 이용 안내, "계정 및 고객지원" = 계정 및 보안·공지사항·고객센터·서비스 정보, 줄에는 아이콘·이름·화살표만 보이고 설명은 접근성 읽기에만 씀) (맨 아래 로그아웃·앱 버전 버튼은 환경설정 화면으로 옮겼다). 항목 정의와 누를 때 동작(`itemAction`)·묶음(`MENU_SECTIONS`, `menuSections`)은 `menuItems.js` 에 모여 있다. 타임라인(예전 이름 가족 랭킹)은 "준비 중" 안내만 나오고, 고객센터는 `/support` 로 간다.
- 지금 화면이 있는 항목: 우리 가족(→ `/family`: 구성원·역할·내 프로필·가족 나가기), 계정 및 보안(→ `/account-security`: 기존 `AccountCard` 의 이메일 인증·소셜 계정 연동·로그인/로그아웃을 그대로 담은 화면). AI 리포트(→ `/report`, 1단계 규칙 기반 주간 리포트: 이번 주·최근 8주, 공유 일정·완료한 할 일·공유한 문서 집계와 가비의 한마디·인사이트("내가 아직 보지 않은 문서 N건" 포함: 서버 문서 목록의 `seen`, 구버전 서버면 생략), 모든 집계는 앱에서 KST 로 계산, 일정은 첫 진입에 한 번·문서는 주마다 서버 날짜 조건(created_from/created_to)으로 조회해 캐시(서버 PR 배포 전 구버전이면 최신 200건 한계가 남음). 구성·집계 기준은 `docs/requirements/report.md`). 가비 AI 이용 안내(→ `/ai-guide`, 읽기 전용 안내 화면: 가비가 하는 일·@가비 사용법·참고하는/참고하지 않는 정보·개인정보와 외부 AI 처리 안내(소통 탭 "대화 분석하기" 는 별도 확인 없이 바로 전달되고 결과가 약 10분 저장된다는 안내 포함). 문구는 `aiGuide.js` 한 곳에 있고 서버 동작에 맞춰 쓴다. AI 오류 신고·FAQ 는 서버 연동이 필요해 아직 없다). 구독 관리(→ `/subscription`: 오늘 사용량을 "N% 사용됨" 게이지 바(나·가족)로 보인다. `GET /family-chat/ai/settings` 의 `limits`·`usage` 를 `getAiUsage`/`useAiUsage` 로 읽고 횟수는 보이지 않는다. 게이지는 가족 대화 분석의 하루 한도 기준이고 @가비(AI 비서)는 한도가 따로라 들어 있지 않다. 게이지 컴포넌트·계산은 소통 탭 AI 패널과 같이 쓰려고 `shared/components/UsageGauge.js`·`shared/aiUsage.js` 에 있다. 요금제·결제는 "준비 중" 글만 있다). 나머지(타임라인·설정·가족 위치 확인(2026-11-09 가족 공유 문서함에서 이름 변경, 줄 설명은 "가족 위치 공유", 위치 기능은 아직 없음)·공지사항·서비스 정보)는 **"준비 중이에요" 안내만** 나온다. 타임라인은 "준비 중이에요" 안내만 있고 요구사항은 아직 정리 전이다(구현 전). 가비 AI 이용 안내는 켜고 끄는 ON/OFF 설정이 아니라 이용 안내·외부 AI 데이터 처리 설명·개인정보 보호 방식을 읽는 안내 화면이며(`aiGuide.js`), 사용량은 구독 관리(`/subscription`)에서 본다.
- **디자인(2026-11, 문구·항목은 그대로)**: 제목 줄 오른쪽 위는 톱니 아이콘만 있는 환경설정 버튼(`HeaderActions`, 누르는 영역 44x44), 프로필 카드는 큰 아바타(72)와 큰 이름·"내 정보 수정"(꿀색 글자)·화살표, 바로가기 4칸은 카드 하나 안에 세로 구분선으로 나뉜 꿀색 아이콘, 목록은 묶음마다 제목과 둥근 카드(줄마다 복숭아색 둥근 아이콘 칩·이름·화살표, 줄 사이 얇은 선). 메뉴 이름·설명·이동 위치·"준비 중" 안내는 바뀌지 않았다.
- **고객센터 화면(`/support`, 앱 `features/support`)**: 마이 > 고객센터에서 "문의하기"(종류 문의/신고·제목 100자·내용 2000자)로 보내고 "내 문의"에서 상태(접수됨·처리 중·답변 완료)와 관리자 답변을 본다. 서버 `POST /support/tickets`·`GET /support/tickets/mine`(docs/requirements/support.md)을 쓰고, 신고에도 사용자가 쓴 글만 보낸다. 답변은 "내 문의"에서 본다. 답변이 저장되면 알림함에 "고객센터" 분류로 알림이 뜨고 누르면 `/support?tab=mine` 으로 간다(서버가 기록, `docs/features/notifications.md`). 마이 > 고객센터 줄은 이 화면에 연결돼 있다(서버 문의 API 병합 후).
- 가족 정보(이름·역할·가입 요청 수)는 다른 기능이라 라우트(`app/(tabs)/my.js`)가 `useFamilyState` 로 읽어 `MoreScreen` 에 props 로 넘긴다.
- 각 탭 화면 위의 **설정 버튼(톱니바퀴)과 AI 채팅의 ⋮ 는 없앴다**(설정은 하단 "마이" 탭에서 들어간다). 예전 주소 `/more` 는 `/my` 탭으로 보낸다(`app/more.js` 가 리다이렉트).
- **고객센터 화면 구성(2026-11)**: "문의하기"(무엇을 도와드릴까요? 안내 → 문의/신고 선택 카드 → 제목·내용 → 안내 박스 → 보내기)와 "내 문의"(필터 칩 전체·답변 대기·답변 완료 + 건수 → 상태 뱃지가 붙은 접히는 카드, 질문 Q·답변 A 구분, 비었을 때 안내와 "문의하기" 버튼, 오른쪽 위 새로고침)로 이뤄진다. 답변이 있으면 서버 상태와 상관없이 "답변 완료"로 보이고, 답변 없이 닫힌 것은 "처리 완료"다(`features/support/messages.js` 의 `ticketView`·`ticketCounts`·`filterTickets`, 카드는 `components/TicketCard.js`·`KindPicker.js`). "답변이 달리면 알림으로 알려 드려요" 문구는 답변 알림 서버 기능(`kind=support`)이 있어야 사실이 된다.
- AI 채팅 홈은 크림 바탕에 복숭아색·꿀색이 번지는 배경(`shared/components/SoftBackdrop`, `react-native-svg`)을 쓴다. 빈 화면과 대화 중 모두에서 그린다. 화면 바탕은 불투명한 크림색으로 두고 그 위·내용 뒤에 그린다. 다른 탭은 단색이다.
- **환경설정 화면(`/settings`, `SettingsScreen`, 2026-11)**: 제목 "환경설정"과 뒤로 가기. 구역은 일반(앱 버전 줄, 오른쪽에 버전, 누를 수 없음) → 시스템 설정("준비 중이에요" 안내 줄) → 알림설정(→ `/push-settings`) → 개인 보안(로그아웃: 로그인 상태에서만 보이고, `signOut` 뒤 `/` 로 이동). 줄은 마이 페이지 목록(`MenuList`, `value`·`static` 항목 추가)을 재사용하고 구성·누를 때 동작은 `settingsItems.js`(`settingsSections`·`settingsAction`)에 있다.
- 앱 버전은 `app.json` 의 version(`expo-constants`)을 `versionText` 로 보인다(환경설정 화면 "앱 버전" 줄).

## 일부러 뺀 것
- **테스트 동의서 다시 보기**: 동의서 화면은 "동의하지 않으면 앱을 닫는" 첫 동의 흐름이라 마이 페이지에서 다시 열면 위험하다. 읽기 전용 화면이 생기면 연결한다.
