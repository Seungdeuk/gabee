# 구현 현황: 마이 페이지 (more)

서버 기능은 없다(앱 화면만). 요구사항 문서도 없어 사용자(정산·돌봄 담당)가 구성을 직접 정했다.

## 구현된 것 (`apps/mobile/src/features/more`)
- **하단 마지막 탭 "마이"**(`app/(tabs)/my.js`): `MoreScreen` 을 연결한다. 제목은 "마이페이지". 탭은 AI 채팅·소통·일정·돌봄·마이 5개다.
- 구성(위에서 아래): **프로필 카드**(`ProfileCard`: 이름, 가족 이름 · 가족 내 역할, "내 정보 수정" → `/family-profile`, 로그인 전에는 로그인 안내) → **바로가기 4칸**(`ShortcutGrid`: AI 리포트·구독 관리·가족 랭킹·설정) → **목록 6줄**(`MenuList`: 우리 가족·가족 공유 문서함·가비 AI 이용 안내·계정 및 보안·공지사항·서비스 정보) → 맨 아래 **로그아웃 · 앱 버전**. 항목 정의와 누를 때 동작(`itemAction`)은 `menuItems.js` 에 모여 있다.
- 지금 화면이 있는 항목: 우리 가족(→ `/family`, 관리자에게는 "요청 N건" 태그), 계정 및 보안(→ `/account-security`: 기존 `AccountCard` 의 이메일 인증·소셜 계정 연동·로그인/로그아웃을 그대로 담은 화면). AI 리포트(→ `/report`, 1단계 규칙 기반 주간 리포트: 이번 주·최근 8주, 공유 일정·완료한 할 일·공유한 문서 집계와 가비의 한마디·인사이트("내가 아직 보지 않은 문서 N건" 포함: 서버 문서 목록의 `seen`, 구버전 서버면 생략), 모든 집계는 앱에서 KST 로 계산, 일정은 첫 진입에 한 번·문서는 주마다 서버 날짜 조건(created_from/created_to)으로 조회해 캐시(서버 PR 배포 전 구버전이면 최신 200건 한계가 남음). 구성·집계 기준은 `docs/requirements/report.md`). 구독 관리(→ `/subscription`: 오늘 사용량을 "N% 사용됨" 게이지 바(나·가족)로 보인다. `GET /family-chat/ai/settings` 의 `limits`·`usage` 를 `getAiUsage`/`useAiUsage` 로 읽고 횟수는 보이지 않는다. 게이지는 가족 대화 분석의 하루 한도 기준이고 @가비(AI 비서)는 한도가 따로라 들어 있지 않다. 게이지 컴포넌트·계산은 소통 탭 AI 패널과 같이 쓰려고 `shared/components/UsageGauge.js`·`shared/aiUsage.js` 에 있다. 요금제·결제는 "준비 중" 글만 있다). 나머지(가족 랭킹·설정·가비 AI 이용 안내·가족 공유 문서함(줄 설명은 "가족 공지 · 업로드")·공지사항·서비스 정보)는 **"준비 중이에요" 안내만** 나온다. 기능 정의: 가족 랭킹은 가비 AI 이용 안내는 ON/OFF 대신 이용 안내·외부 AI 데이터 처리 설명·사용량·개인정보 보호 방식이다(구현 전).
- 가족 정보(이름·역할·가입 요청 수)는 다른 기능이라 라우트(`app/(tabs)/my.js`)가 `useFamilyState` 로 읽어 `MoreScreen` 에 props 로 넘긴다.
- 각 탭 화면 위의 **설정 버튼(톱니바퀴)과 AI 채팅의 ⋮ 는 없앴다**(설정은 하단 "마이" 탭에서 들어간다). 예전 주소 `/more` 는 `/my` 탭으로 보낸다(`app/more.js` 가 리다이렉트).
- AI 채팅 홈은 크림 바탕에 복숭아색·꿀색이 번지는 배경(`shared/components/SoftBackdrop`, `react-native-svg`)을 쓴다. 빈 화면과 대화 중 모두에서 그린다. 화면 바탕은 불투명한 크림색으로 두고 그 위·내용 뒤에 그린다. 다른 탭은 단색이다.
- 앱 버전은 `app.json` 의 version(`expo-constants`)을 `versionText` 로 보인다.

## 일부러 뺀 것
- **테스트 동의서 다시 보기**: 동의서 화면은 "동의하지 않으면 앱을 닫는" 첫 동의 흐름이라 마이 페이지에서 다시 열면 위험하다. 읽기 전용 화면이 생기면 연결한다.
