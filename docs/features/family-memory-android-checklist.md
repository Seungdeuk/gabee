# AI 추억 화면 Android 수동 검증 체크리스트

개발자가 실기기나 에뮬레이터에서 5~10분이면 확인할 수 있게 정리했다. 이 PC 에서는 실기기·에뮬레이터가 없어 **아직 아무도 수행하지 않았다(미검증).** 결과를 PR 이나 이 문서에 적어 주세요. 실제 가족 사진을 쓰지 말고 mock 또는 개발 서버의 테스트 계정만 쓴다.

## 준비
- 개발 빌드(Expo Go 불가 시 개발 빌드)로 실행한다. `.env`: `EXPO_PUBLIC_FAMILY_MEMORY_UI=mock`(1단계) → `on`(2단계, 개발 서버에서 서버 `FAMILY_MEMORY_CANDIDATES_API_ENABLED=true`).
- 기본(변수 비움)에서는 가족방 서랍에 "가족 추억 후보" 줄이 **없어야 한다**(확인 0번).

## 0. 기본 꺼짐
- [ ] 변수를 비운 빌드: 가족 채팅방 서랍(채팅 관리)에 "가족 추억 후보"가 보이지 않는다. 기존 줄(미디어·가족 타임라인 등)은 그대로.

## 1. mock 모드 (API 를 부르지 않음)
- [ ] 서랍 → "가족 추억 후보": 화면 제목 "가족 추억 후보", 안내문, 카드 3개(합성 후보).
- [ ] 카드 제목이 날짜뿐이다("2026년 5월 2일 ~ 5월 3일" 등, 장소·사람·감정 문구 없음). 부제 "사진 N장", 날짜 없는 사진이 있으면 "촬영 날짜 없는 사진 N장 포함".
- [ ] 카드 이미지는 회색 바탕이다(합성 사진 id 라 서버에 없음 — 정상). 맨 아래 "개발용 합성 데이터예요" 문구.
- [ ] 카드를 누르면 사진 모아보기(3열), 대표 사진에 "대표" 표시. 사진을 누르면 앨범 뷰어가 열리고 아래에 날짜(없으면 "촬영 날짜를 알 수 없어요").
- [ ] 뒤로 가기: 뷰어 → 상세 → 목록 → 이전 화면 순서로 닫힌다.
- [ ] 당겨서 새로 고침이 동작한다(오류 없이 같은 목록).
- [ ] 좁은 화면(작은 폰, 글꼴 크게)에서 제목·부제가 잘리지 않고 카드·그리드가 화면을 넘지 않는다.

## 2. 개발 서버 `on` 모드
- [ ] 후보가 없는 가족: "아직 추억 후보가 없어요"(정상 빈 상태) + 새로 고침 버튼.
- [ ] 서버 가드가 꺼진 개발 서버(`FAMILY_MEMORY_CANDIDATES_API_ENABLED=false`): **"추억 기능은 아직 열려 있지 않아요"** 가 보이고 "추억 없음"이 아니다.
- [ ] 후보가 있는 가족(서버에서 합성 사진으로 `refresh` 호출 후): 카드·실제 썸네일이 로드되고, 원본이 뷰어에서 열린다.
- [ ] 네트워크 끊김(비행기 모드) 상태에서 열기: 연결 실패 안내 + "다시 시도". 연결을 되돌리고 누르면 불러온다.
- [ ] 로그인 만료(서버에서 세션 만료): 로그인 만료 안내 또는 로그인 화면으로 이동, 이전 목록이 남지 않는다.
- [ ] 이미지 로딩 실패(서버에서 사진을 지움): 해당 사진이 목록에서 빠지고, 3장 미만이 되면 카드가 사라진다.

## 3. 개인정보·초기화
- [ ] 가족 전환(다른 가족 활성화) 즉시 이전 가족의 카드·사진이 화면에서 사라지고 새 가족 목록을 불러온다.
- [ ] 로그아웃 후 다른 계정으로 로그인: 이전 사용자의 후보·사진이 보이지 않는다.
- [ ] 서버에서 동의 철회/사진 제외/삭제 후 앱 새로 고침: 해당 사진이 즉시 사라진다.
- [ ] (선택) 앱 정보에서 저장공간이 로그아웃 뒤 줄어든다(이미지 캐시 정리).

## 4. 기존 화면 영향 없음
- [ ] 가족 타임라인, 채팅 사진 보기, 사진 확인 필요 목록이 평소처럼 동작한다.
