4. 즉시 중단: 보안 위반, 승인 없는 쓰기, 비용 통제 실패(`BudgetExceeded`·승인액 초과), 실행 커밋·프롬프트 해시 불일치. 중단하면 원인을 보고하고 다음 배치는 새 승인 전에 시작하지 않는다.
5. 배치마다 Preflight 를 다시 돌려 9/9 를 확인한 뒤 실행한다. 전체 결과는 4배치가 모두 끝난 뒤 한 번에 집계한다.
6. 단일 메인 checkout 에서 승인된 커밋에 분리(detach)해 실행하고, 끝나면 원래 위치로 되돌린다.

## 8. 준비 상태와 남은 차단 조건
- **준비 완료:** 코드·Preflight(4배치 9/9)·배치 구성·해시·비교 계획·중단 규칙.
- **남은 차단 조건(실제 호출 전):** ① 사용자의 배치별 비용·실행 승인(권장 합계 $1.54, 예상 실제 $0.30~0.48) ② 실행 시점의 `release/1.4` HEAD 동결 확인(그 사이 병합이 생기면 재점검) ③ 팀 병합 정책상 보류 중인 PR(#538 등)은 평가와 무관하지만, 평가 후 병합될 변경과 구분해 기록. GitHub Actions 결제 문제와 #526(PostgreSQL e2e 기존 실패)은 별도 위험이다.
