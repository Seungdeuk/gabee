# NER 운영 교체 평가 프로토콜 (S0 vs R11 B-new seed 21) — ops-1.0

2026-11-23 작성. **상태: 제안(PROPOSED). 사용자 승인·커밋·태그 전에는 효력이 없다.** 독립 평가셋은 아직 없고 개봉·실행·운영 교체는 하지 않았다.
표시: **자동 검증 기반 연구용 · 사람 검수 미완료.** 이 문서는 R11 연구 게이트(G1~G12, R1~R4, R11-S)와 그 결론을 바꾸지 않는다. 운영 교체 평가는 별도 판정이다.

## 2. 연구 상태의 보존(공식 연구 게이트 통과가 아니다)

- B-new 모델군은 **R11-S 미충족**(적격 시드 1/5, 4개 이상 필요). 사전 등록 규칙상 선정 후보는 없었다. seed 21 은 개별 게이트 통과 시드일 뿐이다.
- 사람 의미 검수 519건 미완료. 데이터 품질 불확실성은 자동 검증으로 대체되지 않는다(Development 표면 오류 3행 포함).
- 이 평가는 "S0 대비 운영상 이득과 위험"을 새 독립 평가셋으로 보는 별도 절차이며, 통과해도 R11 연구 게이트를 통과했다고 쓰지 않는다.
- **시드 재현성 위험**: seed 21 은 최선 시드 선택이라 독립 평가 성능이 5시드 평균 쪽으로 낮아질 수 있다(승자의 저주). 같은 학습을 다시 하면 다른 모델이 된다. 이 위험은 결과 해석과 롤아웃 단계(§7)에서 계속 표기한다. 판정 기준 여유는 Development 차이(Recall +32.6pp)의 1/3 수준으로 잡았다.

- 모두 충족해야 `REPLACEMENT_CANDIDATE`. 하나라도 미충족이거나 구간이 기준을 가로지르면 `KEEP_S0`. 임계값 수정·다른 시드로 재평가 금지.
- 임계값의 근거: P5·P8·P9·S1 의 절대 한도는 연구 게이트(G1·G6·G7·G11)의 고정값을 그대로 가져왔고, 독립 평가셋 구성이 달라 P5 만 여유를 두었다. 임계값은 Development 결과를 참고해 정했으며 독립 평가 결과를 본 뒤 바꾸지 않는다.

## 4. 통계
쌍체 군집 부트스트랩(쌍이면 pair_id, 아니면 문장; 5,000회, 시드 20261123, 95% percentile). 같은 재표본을 두 모델에 적용. 절대 변화(%p)와 상대 변화율, 구간을 모든 지표에 보고. 평가셋 라벨 오류와 사람 검수 미완료에 따른 불확실성은 구간에 포함되지 않는다(별도 한계).

## 5. 독립 평가셋 (`NER_R11_EVALSET_SPEC.md` r11-1.0, 2,350문장)
- 구성: 사람 1,800 / 기타만 50 / 없음 500. D1P 300 + D1 300(**300쌍**, 75단어 이상, 단어당 4쌍 이하), B1 240, C2 200, NEWNAME 310, LONGNAME 120, ORGLOC_MIX 100, 기존 서비스 회귀 유형 A1·A3·B2·C1·D3·D2·A3N·GENERIC·OTHER.
- 제작: 지시서(`NER_R11_EVALSET_PRODUCER_INSTRUCTIONS.md`)만 받은 **별도 세션의 제작자**. 이 세션(학습 세션)은 제작·열람하지 않는다(독립성). 학습·Validation·Development 와 문장 일치 0, 틀 겹침 2% 이하, 4-gram 유사 3% 이하를 검증기(`validate_r11_evalset.py --reference-dir`)로 확인.
- 도구 상태: 변환기·검증기 완료, **봉인 `seal_r11_evalset.py`·`verify_r11_seal.py`·평가 실행기 `evaluate_ops_final.py` 준비 완료(시험 8건)**. 봉인 실행과 평가 개봉은 승인 후.
- **의미 품질 위험**: 라벨 정합성은 자동 검증(스키마·span·쌍 규칙·중복)으로만 확인되며 사람 의미 검수를 대체하지 못한다. 대응: (1) 사람 표본 검수(전체 15% 이상, 쌍 60·LONGNAME 30·ORGLOC_MIX 30 이상, 2명 독립 판정)를 권장하며 미실시 시 매니페스트에 "미완료" 기록, (2) 검수 불일치율 추정치로 구간 해석에 한계 병기, (3) 자동 점검 표면 오류는 수정·삭제 없이 목록만 보존.
- 봉인: 승인 해시 대조 → strict 검증 → 읽기 전용 복사 → `MANIFEST.sha256`. 봉인 폴더는 학습·선정 코드 경로 밖. 평가는 `EVALUATED.lock` 으로 1회만.

## 6. 실제 가명화 파이프라인 검증(외부 전송 없음, 합성 데이터만)
구성: 규칙 탐지(`detectors`) + 등록 이름 사전 → NER(`ner.spans_for`) → `merge_ner` → `Pseudonymizer.apply`(요청 단위 토큰 `[PERSON_n]`) → 외부 호출 → `restore`. 모델 교체가 영향을 주는 곳은 아래 **A 경로**와 가계 에이전트의 질문·history 뿐이다.

| 구분 | 경로 | NER 교체 영향 |
|---|---|---|
| A. NER 포함 가명화 | 가족채팅 AI(분석·답장·주제·미리보기), 가족채팅 탭 에이전트, @가비 방 맥락, 일정 에이전트 채팅, 주간 뉴스 라벨, quiz | 있음 |
| B. 부분 적용 | 가계 에이전트(질문·history 만 NER, **도구 결과는 가명화 없음**) | 질문·history 만 |
| C. 규칙 `mask_text` 만(이름 사전·NER·가명화 토큰 없음) | 일정 제안, 일정 call_talk, 관리자 챗봇, 일정 습관·목록 제목 | 없음 |
| D. 가명화 없이 전송 | 메인 AI 채팅(ADR 0014 로 게이트웨이 연결 철회, 방 대화 맥락만 가명화), 문서 업로드 OCR·PII 탐지(원문/이미지 전송), 사진 판별, 알림 계획 | 없음 |

- 이 구분은 모델 교체와 별개로 보고하며 B~D 가 모델 교체로 개선되지 않는다는 점을 사용자에게 명시한다.
- 검증 항목(오프라인, 기존 도구 재사용): ① 실모델 스모크 `GABEE_NER_TEST_MODEL_DIR` 로 `test_ner.py` 실모델 시험 3건, ② 가명화·복원 왕복 `diag_roundtrip.py`(합성), ③ 가짜 `httpx.post` 로 최종 요청 본문 캡처 `eval_workflows.py`(누출 검사), ④ 두 모델 쌍체 비교 `compare_two_models.py`, ⑤ 지연·메모리 `diag_prod_env_bench.py`, ⑥ fail-closed 시험(`test_ner.py`: required 에서 모델 없음·해시 불일치·타임아웃 시 503), ⑦ 도구 결과 복원·재가명화(`family_chat/agent.py` 경로).
- **운영 모드 위험**: 코드의 기본 `PRIVACY_NER_MODE` 는 `auto` 이고 `auto` 는 모델을 못 쓰면 **규칙만으로 외부에 전송(fail-open)**한다. 운영 환경변수는 저장소에서 확인할 수 없다. 교체 전 운영이 `required` 인지 확인하고, `auto` 면 "NER 로딩 실패 시 외부 호출 차단" 요구를 충족하지 않는다는 사실을 보고한다. 모드 변경은 별도 승인.
- 실제 사용자 개인정보·가족 채팅 원문은 외부 LLM 에 보내지 않는다. 전 항목은 합성 문장·가짜 전송 계층으로만 수행한다.

## 7. 교체 계획(독립 평가 통과 + 사용자 최종 승인 후에만)
1. **백업**: S0 폴더(`model.onnx`·`tokenizer.json`·`labels.json`·`model_card.json`)를 해시와 함께 `ner.prev` 로 보존, 이전 서비스 이미지 태그 보존.
2. **배포 준비**: B 폴더(`r11-B-s21-ep5`)를 같은 이름 규칙의 폴더로 준비. 운영은 `Dockerfile` 이 `data/models` 를 이미지에 COPY 하므로 **교체와 롤백 모두 이미지 재빌드·재배포가 필요**(폴더 이름 `ner-koelectra-small-v2b` 가 Dockerfile 에 고정). `model_card.json` 의 sha256 에 모델·tokenizer·labels 해시가 모두 있어야 무결성 검사가 완전하다(B 는 충족).
3. **테스트 환경 로딩 검증**: `ner_status().fingerprint`(= model.onnx sha256 앞 12자 `3831601b7ffb`), 라벨 매핑(`LABEL_TO_KIND`)에서 PERSON·PERSON_ALIAS·ADDRESS 가 그대로 쓰이는지, 워밍업 통과.
4. **그림자 검증**: 외부 호출 없이 S0 와 B 를 같은 합성·등록 이름 코퍼스에 병렬 실행해 스팬 차이만 집계(문장 원문 로그 금지).
5. **제한적 전환**: 일부 환경(내부 사용자)부터 `required` 모드로, 지표(503 비율, p50/p95 지연, RSS, PERSON 검출 비율)만 모니터링.
6. **롤백 기준**: 모델 로딩 실패·해시 불일치, 503 비율 증가, p50 지연 > S0×1.3 지속, RSS > S0+30%, 노출 사고 보고, 검출 비율의 급변. 즉시 이전 이미지 태그로 되돌린다(모델은 시작 시 1회 로드, hot reload 없음, `reset()` 은 운영에서 쓰지 않음). 롤백 후 `ner_status` 지문이 S0 `46210943c45f` 인지 확인.
- **운영 배포는 이 문서·독립 평가 결과를 보고한 뒤 사용자의 별도 최종 승인으로만 진행**한다.

## 8. 독립 평가 실행 전 남은 필수 조건
1. 이 프로토콜·판정 기준의 사용자 승인과 커밋·태그(예: `r11-ops-prereg-1.0`).
2. 독립 평가셋 제작(별도 제작 세션)·검증·겹침 측정·(권장) 사람 표본 검수·봉인 승인.
3. 운영 서버가 실제로 쓰는 S0 해시·`PRIVACY_NER_MODE` 확인(운영 담당자).
4. 평가 개봉·실행 승인.
