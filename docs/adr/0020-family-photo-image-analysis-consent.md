# 0020. 가족 공유 사진의 이미지 분석(AI 추억 발견)은 자체 서버에서만, 기본 꺼짐·3중 조건(서버 스위치·가족 활성화·업로더 동의)으로만 한다

- 날짜: 2026-11-17
- 상태: **초안 정책 — 승인된 것은 문서 작성까지다. 운영 기능 활성화는 승인되지 않았다.** 이미지 분석 서비스 코드·DB 변경은 이 ADR 이 병합된 뒤 별도 승인으로 진행한다.
- 결정:
  - **분석 위치:** 가족 공유 사진의 이미지 분석은 가비 서버 안에서만 한다. 원본 이미지를 외부 AI 서비스(LLM·Vision API 포함)로 보내지 않는다.
  - **금지:** 얼굴 식별, 인물 관계·감정 추론, 장소 특정. 분석 결과는 장면·주제 점수와 임베딩 같은 **파생 특징**만 남기고 이미지는 복사하지 않는다.
  - **3중 조건(모두 충족해야 분석):** ① 서버 기능 스위치(환경변수, **기본 꺼짐**) ② 가족 단위 활성화 ③ 사진을 올린 구성원의 AI 분석 동의. 하나라도 빠지면 분석하지 않는다. 동의하지 않은 사진은 이미지 분석을 하지 않는다.
  - **분석 대상:** 위 3중 조건에 더해 기존 타임라인 공개 조건(가족 전체방 사진, 상태 `photo`, 업로더가 타임라인에서 빼지 않음)을 만족한 사진뿐이다. 문서·불확실·판별 실패·제외된 사진과 1:1 방 사진은 분석하지 않는다. 문서 안전 게이트(D-13 포함)와 추억 발견은 서로의 입력·스위치·대기열을 공유하지 않는다.
  - **권한(기존 `group_members.role` 사용, 새 역할 없음):**
    - owner/admin(`join_service.require_manager` 와 같은 기준): 가족 AI 추억 기능 활성화·비활성화.
    - member: 가족 기능 활성화 권한 없음.
    - 모든 구성원: 자신이 올린 사진의 AI 분석 동의·철회, 개별 사진의 AI 분석 제외.
    - 신규 구성원: 켜진 가족에 가입하면 별도 안내를 보여 주고, 본인 동의 전에는 그 사람의 사진을 분석하지 않는다.
  - **제외 종류 구분:** "AI 분석 제외"는 타임라인 노출과 별개다(타임라인에는 보이고 분석만 제외). 기존 "타임라인에서 빼기"(`excluded`)와 섞지 않는다.
  - **동의 철회:** 업로더가 철회하면 (1) 그 사람 사진의 새 분석을 중지하고 (2) 기존 임베딩·장면 분석 결과를 삭제하고 (3) 해당 사진을 AI 추억 그룹에서 제외하고 (4) 영향을 받은 추억의 제목·이야기를 재생성한다. **재생성이 끝나기 전에는 영향을 받은 기존 추억을 노출하지 않는다.** 기본 가족 채팅과 날짜별 사진 공유 기능에는 영향이 없다.
  - **가족 비활성화:** 가족이 기능을 끄면 그 가족의 파생 데이터(특징·추억)를 삭제한다.
  - **동의 기록:** 동의 버전·동의 시각·철회 시각 등 최소 정보만 둔다. 구체적인 보관 기간은 개인정보 처리 기준과 팀 정책 검토 뒤 확정한다(이 ADR 에서 정하지 않는다). 동의 내용 원문을 불필요하게 오래 보관하지 않는다.
  - **과거 사진:** 기존 사진의 소급 분석은 기본 꺼짐이다. 나중에 별도 기능으로 제공하되, 업로더가 소급 분석에 명시적으로 동의한 사진만 대상으로 한다.
  - **로그:** 사진 내용·라벨·이야기 본문·임베딩을 로그에 남기지 않고, 임베딩을 API 로 내보내지 않으며, 가족 간 비교를 하지 않는다.
- 이유:
  - 제품 방향(가족 사진 속 특별한 순간을 AI 가 발견해 추억으로 묶어 주는 가족 전용 공간)은 이미지 이해가 핵심이지만, 가족 사진(얼굴·집·아이)을 읽는 새 처리 경로라 동의 없이 켤 수 없다.
  - 가족 관리자와 업로더의 동의를 따로 받는 이유: 가족 단위 스위치만으로는 사진 주인의 의사를 대신할 수 없고, 업로더 단위 동의만으로는 가족이 기능 도입 자체를 정할 수 없다.
  - 서버 스위치를 기본 꺼짐으로 두는 이유: 코드가 배포되어도 동의·고지 문서가 완성되기 전에는 분석이 실행되지 않게 하기 위해서다.
- 대안:
  - **외부 Vision API 로 분석:** 원본 이미지가 외부로 나가는 경로가 생겨 채택하지 않는다.
  - **가족 단위 동의만 받기:** 개별 사진 주인의 동의를 건너뛰므로 채택하지 않는다.
  - **모든 가족이 기본 켜짐(opt-out):** 고지·동의 전에 분석이 시작될 수 있어 채택하지 않는다.
- 결과·주의:
  - 이 ADR 병합만으로 운영에 아무 일도 일어나지 않는다. 이미지 분석 코드·테이블은 모델 성능 검증(오프라인 벤치마크, 가족 사진 사용 금지) 이후 별도 PR·별도 승인으로 추가한다.
  - 구현 시 필요한 시험: 스위치가 꺼져 있으면 분석이 호출되지 않음, 가족 비활성·업로더 미동의·분석 제외·타임라인 제외 사진은 분석 대상에서 빠짐, 철회 시 파생 데이터 삭제와 재생성 전 노출 차단, member 의 가족 활성화 시도는 403.
  - 개인정보처리방침(T31)·Play 데이터 안전 양식에 "가비 서버 안에서만 사진 내용을 분석하며 외부로 보내지 않고 얼굴을 식별하지 않는다"를 반영해야 활성화할 수 있다.
  - 미결정: 동의 기록 보관 기간, 철회된 추억 재생성의 대기 시간 상한, 소급 분석 기능의 화면·고지.
  - 관련: `docs/requirements/timeline.md` (T42, Q7·Q8·Q9), ADR 0015.
