# 0023. 가명화 보강 NER 모델은 기존 서비스 모델을 유지하고 R6+B 적용은 보류한다(미채택)

- 날짜: 2026-11-18
- 번호 비고: 처음에는 0021 로 "R6+B 채택" 초안을 썼다. 그런데 `release/1.3` 에 `0021-auto-memory-exposure-policy.md` 가
  이미 있고 0022 는 PR #445 에서 제안 중이라 0023 으로 옮겼다. 처음 초안(채택 문구)은 백업 브랜치
  `experiment/ner-r6b-decoder-patch` 에만 남아 있고 어떤 기준 브랜치에도 합치지 않는다.
- 결정:
  - 서비스 NER 모델은 `v2b-koelectra-small-klue10-s7`(지문 `46210943c45f`)을 그대로 쓰고, BIO 디코딩(`NerEngine._decode`)도
    지금 그대로 둔다.
  - R6+B(R6 가중치 `c59b174ba126` + 실험 B 병합 완화)의 **운영 적용은 보류(미채택)** 한다. 실험 결과와 코드는 지우지 않고
    연구 산출물로 남긴다.
  - 추가 NER 모델 학습·파인튜닝·평가셋 제작은 이 결정으로 종료한다.
- 이유(자세한 수치와 조건은 `docs/security/NER_VALIDATION.md` 70절):
  - R6+B 는 완전노출률을 줄이는 평가셋이 많지만, 부분노출률은 v7_namefreq(1.58%→3.46%)와 Nemotron 전체 이름
    (2.60%→4.32%)에서 오히려 늘었다.
  - 전체 이름 노출률은 평가셋마다 개선과 악화가 엇갈린다(v7_namefreq 6.88%→8.08% 악화, realistic_family
    12.50%→9.00% 개선, Nemotron 합산 5.84%→5.66% 소폭 개선, v14_realistic 동일).
  - 비PERSON 오탐이 측정된 평가셋에서 같거나 악화됐다(v7 43.59%→61.54%, realistic_family 18.18%→22.73%,
    v14_realistic 0→5%(1/20), v13 8.33% 동일). 일반 대화를 사람 이름으로 잘못 가리는 사용성 문제로 이어진다.
  - 일반 한국 사람 이름 가명화 목적에서 기존 서비스 모델 대비 **일관된 우위가 입증되지 않았다.** R6+B 의 큰 개선(v13 전체노출
    64%→17.5%)은 낯선 합성 단어 스트레스 평가에 집중돼 있다.
- 대안:
  - **R6+B 채택**: 위 이유로 보류. 교체하려면 운영 `ner.py` 디코더 변경과 Docker 이미지 재빌드(모델이 이미지에 `COPY` 로 들어감)가
    필요해 비용도 크다.
  - **R6 단독(병합 완화 없이)**: 부분노출이 서비스보다 나빠져(v13 3.0%→9.0%) 반려했다.
  - **실험 A(재학습으로 토큰 중간 "O" 해결)**: 인접 개체 과잉병합·중의성 오탐 악화가 확인돼 보류(59~63절).
- 결과·주의:
  - 서비스 모델의 알려진 약점은 그대로 남는다: 처음 보는 낯선 이름·한 글자 이름·공백 없이 붙은 별명(예: "민준이형서윤이가"는
    R6 도 하나로 합침). 등록된 가족 이름은 NER 과 무관하게 이름 사전이 1차로 보호한다.
  - 실제 운영 컨테이너가 로드 중인 모델 지문과 `PRIVACY_NER_MODE` 값은 이 저장소만으로 확인할 수 없다(미확인). 이 PC 의
    `data/models/ner` 활성 폴더는 R1(`c536eadeb5a1`)이고 `ner.prev` 가 서비스 모델이므로 "서비스 모델"이라고 부를 때 어느
    폴더를 가리키는지 주의한다.
  - 다시 검토하려면 새 실험이 아니라 운영 피드백(실제 노출·과잉 가림 사례)으로 필요성이 확인됐을 때 별도 안건으로 올린다.
