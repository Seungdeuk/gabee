# 0012. 올린 문서의 가족 이름은 `[가족:<user_id>]` 자리표시로 저장하고 읽을 때 되돌린다

- 날짜: 2026-11-02
- 결정:
  - 업로드 때, OCR·변환으로 얻은 글에서 **정규식 가리기(`masking.mask_text`) 이전에** 그 가족 그룹 구성원의 이름·표시 이름을 찾아 `[가족:<구성원 user_id>]` 로 바꾼다(`ai_assistant/family_names.py`, 연결은 `ingest/service.py` 의 `_mask`). 이 글이 분류(외부 서비스 Jev 로 나갈 수 있음)·저장에 쓰이므로 가족 실명이 외부로 나가지 않는다.
  - 기록(`knowledge_items`)에 `family_user_ids`(nullable JSON 문자열 배열) 칸 하나를 **추가만** 한다(Alembic 7b3d9e1a4c52, expand). 값은 저장하는 글(title·body_md)의 자리표시에서 뽑는다.
  - 읽을 때(기록 상세·목록·검색·찾기 응답, 파일 상태의 제목·설명, 기록 도구 `search_knowledge`/`get_item`/`list_items` 결과) `[가족:<id>]` 를 그 그룹의 **현재** 표시 이름(없으면 실제 이름)으로 바꾼다. 나간 구성원·모르는 id 는 "가족 구성원".
  - `search_knowledge` 에 선택 인자 `member`(이름·별칭)를 더했다. 서버가 그룹 구성원 사전으로 user_id 를 찾아 그 사람이 등장한 기록만 거른다. 없는 이름이면 빈 결과와 안내 문구를 돌려준다. 같은 이름의 가족이 여럿이면 모두 합쳐 찾고 안내한다. 도구 결과에 `family`(그 기록에 나오는 가족의 현재 이름들)를 더했다.
  - 사용자가 앱에서 고친 글(PATCH)과 사진 설명도 같은 길로 자리표시로 되돌려 저장한다(앱은 이름이 되돌려진 글을 보여 주므로 고친 글에는 실명이 있다).
- 이유: 가리기 뒤에는 `성명: 강민훈` 이 `강**` 가 되어 되돌릴 수 없고 강민훈·강민수가 구분되지 않는다. 가리기 앞에서 user_id 로 바꾸면 누구 이야기인지 남고, 이름을 바꾸거나 구성원이 나가도 현재 이름으로 보이며, 분류·저장에 실명이 들어가지 않는다.
- 이름 찾기 규칙:
  - `shared/privacy/detectors.py` 의 `_detect_person_known`(낱말 속 오탐 방지 `_name_end_ok`, 조사 허용, 성 뗀 이름자 별칭, 일반어 별칭 제외, 가족 호칭 제외)을 그대로 쓴다. 이 모듈은 "찾은 글자가 어느 구성원인가" 만 정한다.
  - **같은 글자가 둘 이상의 구성원에 해당하면(동명이인, 또는 강민훈·이민훈의 `민훈`) 치환하지 않는다.** 임의로 고르면 남의 기록이 된다. 그 글자는 그대로 남아 뒤의 가리기(`강**`)를 받는다.
  - 가림 규칙이 user_id 의 숫자 덩어리를 번호로 오인하지 않게, 가리는 동안에는 짧은 임시 표식으로 바꿔 두었다가 가린 뒤에 `[가족:<id>]` 로 펼친다. 제목 50자 자르기도 자리표시를 반으로 자르지 않는다(`clip`).
- 하지 않은 것:
  - **기존 기록 백필 없음.** 이미 `강**` 로 저장된 기록은 그대로다(원본 글자가 없어 복구할 수 없다). 다시 올리면 새 방식으로 저장된다.
  - 모바일 앱 변경 없음, API 응답 모양(openapi.json) 변경 없음. 서버가 되돌려서 준다.
  - `POST /knowledge/items`(전처리 없이 직접 넣는 시험·개발 경로)는 자리표시로 바꾸지 않는다.
  - 글자 일치 찾기(`/knowledge/find`)는 저장된 글을 그대로 보므로, 가족 이름으로 찾아도 자리표시된 문서는 걸리지 않는다(이름으로 찾기는 `member` 필터 사용).
  - 띄어 쓴 이름("강 민 훈")과 이름 사이 특수 공백은 찾지 않는다. 검색 조각 임베딩은 자리표시가 든 글로 만든다.
- 위험:
  - 구성원 사전에 없는 이름(친척·친구)은 이전과 같이 라벨이 있을 때만 `강**` 로 가려진다.
  - 이름이 일반 낱말과 겹치는 구성원(예: "하나")은 어절 끝이 맞을 때("하나가") 치환된다.
  - 새 컬럼이 있어야 해서 코드를 먼저 배포하면 기능별 스키마 관문(`schema_ready`)이 503 을 낼 수 있다. 마이그레이션을 먼저 적용한다.
  - 도구 결과의 `title`·`text`·`family` 에는 현재 실명이 들어 있다. 외부 모델로 보내기 전에 호출한 쪽(메인 AI 채팅의 가명화 게이트웨이)이 가명화해야 한다.
