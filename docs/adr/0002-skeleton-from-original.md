# 0002. 원본 프로젝트는 뼈대만 가져온다

- 날짜: 2026-10-21
- 결정: 원본(family-secretary_prj)의 코드를 옮기지 않고, 이 레포에는 기능별 **뼈대(베이스 코드)** 만 만든다. 원본은 `docs/legacy/original-reference.md`의 표를 보고 기능을 채울 때 참고한다.
- 이유: 원본은 서버 6개와 웹 화면으로 나뉜 약 4만 줄이라 통째로 옮기면 구조가 무거워지고 팀이 코드를 이해하기 어렵다. 기능 담당자가 자기 기능을 채우면서 필요한 부분만 가져오는 편이 낫다.
- 영향: 서버는 FastAPI 하나, 앱은 Expo 하나로 합친다. 신원 확인은 원본과 같은 토큰 헤더(`X-Gyeot-Token`)를 이어받는다. ADB/MTP 와 웹 화면은 가져오지 않는다.
