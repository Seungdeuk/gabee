# 2026-11-19 체류시간(앱 사용 시간) (kang)

- 관리자 데이터 분석 탭에 "체류시간 (최근 30일)"을 넣었다. 1명당 하루 평균 사용 시간·실행 횟수, 탭별 사용 시간 비율, 날짜별 막대. 유입 경로(#458) 위에 쌓은 브랜치 `feature/kang-usage-time`.
- 사람 수(하루·7일·30일 활성 사용자)는 이미 `refresh_tokens.issued_at` 으로 보고 있어서 다시 만들지 않았다. 토큰 시각은 연 순간만 남고 닫은 순간이 없어서 "얼마나 오래·어느 탭"만 새로 잰다.
- 정밀하게 하지 않기로 했다(사용자 결정): 백그라운드로 갈 때 한 번 보내고, 실패하면 버린다. 5분마다 보내기·휴대폰 보관은 하지 않는다.

- 서버: `POST /usage/report`, 새 표 `usage_daily`(기본키 사람·날·탭, 날짜 인덱스), `app` 줄에 앱 전체 합계와 실행 횟수. Alembic `3ba836194fcf`(down `eab90289ee51`).
