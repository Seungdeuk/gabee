# 2026-11-18 유입 경로(채널별 설치 꼬리표) (kang)

- 가입자가 어떤 홍보 링크(유튜브·인스타·뉴스 등)로 앱을 설치했는지 관리자 페이지에서 보는 기능을 만들었다. PR #458(`feature/kang-acquisition` → `release/1.3`).
  - 사용자에게 묻지 않는다. 채널마다 꼬리표(utm)가 다른 플레이 스토어 링크를 쓰고, 앱이 설치 꼬리표를 읽어 서버에 보낸다.
  - 링크는 구글 "Google Play 캠페인 URL 작성 도구"(ga-dev-tools.web.app/ga4/campaign-url-builder/play/)로 만든다. 앱 ID 는 `com.kangminhun.gabee`(release/1.3 의 app.json, 플레이 스토어 페이지로 확인).
- 서버: `POST /acquisition/install-source`, 새 표 `install_sources`(user_id 기본키), Alembic `eab90289ee51`(표 추가만).
  - 값은 영어 소문자·숫자·`_`·`-` 40자, 처음 값만 남기고, 가입 30일이 지난 회원은 저장하지 않는다(재설치 오집계 방지). 응답은 항상 204.
  - `users` 표에 칸을 넣지 않고 새 표로 했다. 로그인 기능 표라 영향 범위가 커서다.
- 관리자: 데이터 분석 탭 "유입 경로" 표(경로별 가입·비율·가족 연결 비율). 기록 없는 가입자는 "알 수 없음". 표가 없는 DB 에서는 이 구역만 "준비 중"(`schema_status.feature_ready("acquisition")`).
- 앱: `expo-application` 의 `getInstallReferrerAsync()`(안드로이드 전용)로 꼬리표를 읽어 utm 세 값만 로그인 뒤 한 번 보낸다(`features/acquisition/AcquisitionBootstrap.js`, `_layout.js` 의 PushBootstrap 옆).
  - `expo-application` 7.0.8 은 이미 lock 에 있었다(`expo-auth-session`·`expo-notifications` 가 씀). `package.json` 에 직접 등록만 했다.
  - 사용자마다 한 번 확인하면(보냈거나, 꼬리표가 없거나, 플레이 스토어가 꼬리표 기능을 주지 않으면) 다시 묻지 않는다. 플레이 스토어 연결 실패·서버 준비 전(404·503)일 때만 다음 실행 때 다시 시도한다. 처음 버전은 꼬리표 없는 사람에게 앱을 켤 때마다 다시 물어서 고쳤다.
- 시험: 유입 경로 16개, 서비스 관리자·보안 매트릭스·스키마 검사 통과, 임시 PostgreSQL 에서 upgrade·downgrade·스키마 일치, 임시 서버 + 브라우저로 표 확인, 앱 lint 와 꼬리표 함수 직접 실행.
- 중간에 바뀐 것:
  - 처음에는 가입 화면에 "어디서 알게 되셨나요?" 선택지를 넣는 안을 생각했다가, 설치 꼬리표를 읽는 방식으로 바꿨다(가입 방법이 세 가지라 로그인 뒤 한 곳에서 보내는 것이 단순).
  - rebase 중 #455(알림 모델 등록 누락 수정)와 `shared/db.py` 가 겹쳐 두 줄 모두 남겼고, #455 가 추가한 `/health/db` 기능 목록 시험에 `acquisition` 을 넣었다.
- 아직 안 된 것:
  - 배포용 DB 에 새 표 만들기(DB 담당자 Pull Agent) → 서버 배포 → 앱 새 버전 출시.
  - 실제 휴대폰에서 꼬리표가 읽히는지 확인. 플레이 스토어로 설치해야만 값이 나온다(Expo Go·APK 직접 설치·에뮬레이터 불가). 내부 테스트 설치에도 꼬리표가 붙는지는 아직 아무도 확인하지 못했다.
  - 로컬 서버로 시험하려면 내 PC 주소를 넣은 시험용 빌드를 따로 만들어 내부 테스트로 설치해야 한다(릴리스 빌드의 http 차단 여부 확인 필요). 배포 뒤 시험이 더 단순하다.
  - 실제 채널별 숫자는 앱 코드가 들어간 버전이 공개 출시된 뒤부터 쌓인다.
  - 코드 없이 "설치 수"만 보려면 플레이 콘솔(사용자 늘리기 > 스토어 실적 > 전환 분석)에서 UTM 별로 볼 수 있다.
- 팀에 알릴 것:
  - 개인정보처리방침에 "설치 경로(홍보 채널 이름)를 저장한다"는 문구가 필요하다(요구사항 미정 1).
  - 아이폰은 이 방법이 안 된다(앱스토어 커넥트 캠페인 링크 통계로만 본다).
  - `tests/test_model_registry.py` 는 내 PC 가상환경에서 `python -I` 때문에 돌지 않았다. 같은 검사를 직접 돌려 빠진 모델 0개를 확인했다.
