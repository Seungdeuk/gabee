# 기능: AI 채팅 음성 입력

## 목적
사용자가 AI 채팅에서 마이크 버튼을 눌러 말로 물어보면, 폰의 기본 음성 인식이 말을 글자로 바꿔 입력창에 채운다.
오디오는 앱이 저장하거나 서버로 보내지 않고, 서버에는 글자(와 `voice` 표시)만 간다.

## 화면
- AI 채팅 입력창의 마이크 버튼: 누르면 듣기 시작(마이크 권한 요청 → 인식 시작), 듣는 중에는 닫기(×)로 바뀐다.
- 듣는 중에는 "듣고 있어요" 표시와 안내 문구가 나오고, 인식된 글자가 말하는 도중에 입력창에 채워진다.
- 자동으로 보내지 않는다. 사용자가 글자를 확인·고친 뒤 보내기를 눌러야 전송된다.
- 말하기 전에 쳐 둔 글자는 지우지 않고 뒤에 이어 붙인다.
- 권한을 거부했거나 인식을 쓸 수 없으면 안내를 띄우고 글자 입력으로 계속 쓸 수 있다.

## API
- 새 엔드포인트 없음. 기존 채팅 전송을 그대로 쓰고, 클라이언트는 음성으로 받은 글이면 `voice: true`로 표시한다.

## 데이터
- 오디오 저장 없음. 서버 DB 변경 없음.

## 완료 조건
- 마이크 버튼으로 한국어 음성이 입력창에 글자로 채워진다(실제 폰에서 확인).
- 권한 거부, 말 없음, 인식 불가 때 앱이 멈추지 않고 글자 입력으로 이어 쓸 수 있다.
- 음성으로 입력한 글도 일반 글과 같은 서버 규칙(고위험 정보 차단, 가명화)을 거친다.
- 린트와 앱 시험 통과.

## 미정
- 폰 음성 인식 서비스가 오디오를 외부(구글 인식 서비스)로 보낼 수 있다. Play 데이터 보안 양식과 개인정보 처리방침에 어떻게 적을지.
- 삼성·구글 기기와 키보드별 한국어 인식 품질(실제 폰 확인 필요).
