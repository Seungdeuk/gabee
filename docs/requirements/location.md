# 기능: 위치 공유 (베타)

> **베타 브랜치 전용.** `feature/hojenn-location-beta` 에만 있고 `release/1.2`·`deploy/kang`·`main` 에 병합하지 않는다. 운영에 배포하지 않으며, 시연용으로 동의한 팀원·지인의 실제 위치를 로컬 서버에서만 쓴다. 서버 스위치 `LOCATION_ENABLED` 는 기본 꺼짐이다.

## 목적
- 위치 공유에 동의한 사람의 위치를 모아 평소 활동 구역을 만들고, 구역을 벗어나면 부모(관리자)에게 알린다.
- 여행처럼 평소와 다른 곳에 갈 때는 위치 공유를 잠시 멈춰(일시정지) 구역 이탈 알림이 가지 않게 한다.
- 위치 기록에 대해 묻는 에이전트(RAG)는 후속 단계로 둔다(아래 "미정").

## 화면 (돌봄 탭 = 지갑 + 위치)
- 탭 이름은 "돌봄". 위쪽 구분 `지갑 | 위치`. 지갑은 기존 정산·지출·용돈 그대로.
- 위치 구역: ① 동의 카드(안내 문구, 동의/끄고 기록 지우기) ② 여행 모드(1·3·7·14일 일시정지, 다시 공유하기) ③ 가족 위치(지도 타일 없이 상대 위치와 활동 구역을 그린 약식 지도, 구성원별 상태) ④ 시연 도구(활동 구역 빨리 만들기, 구역 이탈 알림 시연, 저장된 내 위치만 지우기).
- 위치는 이 화면이 열려 있는 동안만 1분마다 보낸다(백그라운드 수집 없음).

## API (`/location/*`, 응답 형식은 `docs/contracts/openapi.json`)
| 메서드·경로 | 설명 |
|---|---|
| GET `/location/me` | 내 상태(서버 스위치, 동의, 일시정지, 활동 구역, 모인 위치 수). 스위치가 꺼져 있어도 읽는다 |
| PUT `/location/consent` | 동의/철회. 켜기는 스위치가 켜져 있을 때만, 철회는 항상 열려 있고 저장된 내 위치·구역·설정을 모두 지운다 |
| DELETE `/location/me` | 저장된 내 위치·구역·설정 삭제(동의 상태 유지). 항상 열려 있다 |
| PUT `/location/pause` | `days` 1~14 로 일시정지, 없거나 0 이면 해제. 켤 때 부모에게 "멈췄다"는 사실만 알린다 |
| POST `/location/points` | 위치 하나 올리기(동의·비일시정지일 때만 저장). 구역 밖이면 부모에게 알림 |
| GET `/location/family` | 부모(관리자)는 동의하고 공유 중인 가족 모두의 마지막 위치, 그 밖의 사람은 자기 것만 |
| POST `/location/simulate-exit` | 시연용: 구역을 벗어난 것처럼 판정만 하고 알림을 보낸다(위치는 저장하지 않음) |
| POST `/location/ask` | 위치 기록에 대한 질문(`question` 300자 이내, 앞선 대화 `history`). 스위치가 꺼져 있으면 503, 가족 AI 동의와 하루 한도(위치 에이전트 전용, 사용자 30·그룹 100)를 따른다. 응답 `answer`, `used_tool` |

## 위치 기록 질문 에이전트 (베타)
- 질문 하나를 LLM(`claude-haiku-5-5`, 기존 LLM 래퍼)이 `search_location_history` 도구로 요약 조각을 찾아 그 문장에 있는 사실만 답한다. 도구 인자는 사람 이름·날짜·시각·질문 성격(when_where/count/sequence/anomaly/gap)·찾을 내용이다.
- **권한은 도구를 만드는 서버 코드가 정한다:** 부모(가입 때 부모를 고른 사람, 가족 owner·admin)는 가족 전체, 그 밖의 사람은 본인 기록만 후보가 된다. LLM 이 권한 밖 사람을 골라도 데이터를 돌려주지 않고 "볼 권한이 없어요"만 돌려준다. 시스템 프롬프트에도 볼 수 있는 사람 목록을 주어 권한 밖 질문에는 도구를 부르지 않고 거절하게 한다.
- LLM 이 받는 것: 개인정보를 가린 사용자 질문, 도구가 돌려준 요약 문장(사람·장소 이름·시각, 좌표 없음). 임베딩은 서버에서 계산한다.
- 위치와 무관한 질문에는 도구를 부르지 않고 "가족 위치 기록만 도와드릴 수 있어요"라고 답한다.
- 호출은 `ai_guard`를 거친다(가족 AI 동의 확인, 사용 기록 `location_agent`). 한도는 탭 에이전트와 따로 센다(`AI_LOCATION_AGENT_*`).

## 동작 규칙
- **활동 구역:** 최근 14일 위치가 20개 이상이면 중앙값 중심과 90% 위치까지의 거리×1.2(최소 300m)를 반지름으로 한다. 새 위치가 20개 쌓일 때마다 다시 계산하되, 구역 밖에 있는 동안은 옮기지 않는다. AI를 쓰지 않는다.
- **이탈 알림:** 위치가 반지름(+위치 오차, 최대 100m) 밖이면 부모(가입 때 부모를 고른 사람, 가족 owner·admin)에게 알림(kind `care`, event `zone_exit`). 알림 사이에는 6시간 쿨다운이 있어 경계를 오가도 반복하지 않는다. 즉시 알림이며 본인 확인 단계는 없다.
- **알림 문구:** 고정 문구("평소와 다른 이동이 감지됐어요")만 쓰고 좌표·장소를 담지 않는다. 위치는 앱에서만 본다.
- **일시정지 중:** 위치를 받지 않고 판정하지 않는다.
- **보관:** 위치는 `LOCATION_RETENTION_DAYS`(기본 14일)가 지나면 지운다. 좌표는 로그에 남기지 않는다.
- **동의:** `users.location_consent_at` 이 정본이고, 동의·철회마다 `location_consent_events` 에 이력(경로 `location`)을 남긴다. 동의는 앱에서 위치 권한과 함께 받는다.
- **안내 문구(화면):** 무엇을 모으는지, 누구에게 알리는지, 알림에 위치가 없다는 것, 언제든 끄고 지울 수 있다는 것, 베타라는 것, 급한 일은 112 라는 것.

## 데이터 (Alembic `8a3f6c2d9b15`, 베타 브랜치에만 있음)
- `location_points`: 위치(사용자, 그룹, lat, lng, accuracy_m, 잰 시각, 받은 시각)
- `location_zones`: 사용자별 활동 구역(중심, 반지름, 계산에 쓴 위치 수, 마지막 알림 시각, 지금 구역 밖인지)
- `location_settings`: 사용자별 일시정지 종료 시각

## 미정
- 위치 기록 질문 에이전트(RAG: 요약 문장 청킹·로컬 임베딩·pgvector 검색·답변)와 도구 호출 기록(ToolOps)은 계획 승인 후 진행한다. LLM에는 좌표 없이 요약 문장만 보낸다는 안으로 정했다.
- 14세 미만 보호자 동의, 백그라운드 수집, 시간대별 패턴 분석, 속도·기기 신호 같은 추가 위험 신호는 하지 않았다.
- 구역에 이름(집·학교) 붙이기는 RAG 단계에서 정한다.
