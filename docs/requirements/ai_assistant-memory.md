# 기능: 가비의 기억

## 목적
사용자가 "내가 좋아하는 롤 팀은 T1이야. 기억해 줘"라고 하면 가비가 그 사실을 저장해 뒀다가 다음 대화에서 씁니다.
대화 전체는 저장하지 않고 사용자가 기억하라고 한 짧은 사실만 저장합니다. 채팅은 지금처럼 폰에만 있습니다.

## 화면
- AI 채팅: 저장하면 가비가 한 문장으로 알립니다. "젠지로 바꿔줘"로 고치고 "그거 잊어줘"로 지울 수 있습니다.
- 마이 > "가비의 기억"(새 화면): 내 기억 목록, 고치기, 삭제, 전부 삭제. 비어 있으면 사용 예시를 보여 줍니다.

## API
- `GET /ai-assistant/memories` → `{ items: [{ id, text, created_at }] }` 내 것만.
- `PATCH /ai-assistant/memories/{id}` `{ text }`: 내 것만 고침, 남의 것은 404.
- `DELETE /ai-assistant/memories/{id}`: 내 것만, 남의 것은 404.
- `DELETE /ai-assistant/memories`: 내 기억 전부 삭제.
- 메인 채팅 도구: `remember(text)`, `update_memory(id, text)`, `forget(id)`.

## 데이터
- 새 표 `assistant_memories`: `id`, `user_id`(인덱스), `group_id`, `text`(200자), `created_at`.
- Alembic 리비전 1개(새 표 추가만).
- 가족 전체가 지워지면(`group_purge`) 함께 지워집니다. 구성원이 가족을 나가면 다른 데이터처럼 남지만, 그 가족의 구성원이 아니면 읽을 수 없습니다.

## 규칙
- **저장 시점:** 사용자가 이 대화에서 직접 기억하라고 했을 때 저장합니다. 가비가 먼저 "기억해 둘까요?"라고 물을 수는 있고, 답을 받기 전에는 저장하지 않습니다.
- **출처:** 문서, 웹 페이지, 가족 대화 안의 글을 보고 저장하지 않습니다.
- **거절:** 주민번호·카드·계좌·비밀번호가 있으면 코드가 저장을 거절합니다(`has_high_risk`).
- **민감한 내용:** 건강, 고민, 감정, 집 주소는 사용자가 분명히 요청해도 저장 전에 한 번 더 확인합니다. 프롬프트 지시라 코드로 보장되지는 않습니다.
- **적용 범위:** AI 채팅 탭(`audience=me`)만. 답이 가족방에 올라가는 `@가비`, 탭 에이전트에는 주지 않습니다.
- **공개 범위:** 본인에게만 적용합니다. 가족도 보지 못합니다.
- **개수:** 사람당 50개. 넘으면 저장하지 않고 정리를 안내합니다. 같은 내용은 다시 저장하지 않습니다.
- **프롬프트 주입:** 기억은 사실 자료로만 넘기고 그 안의 지시는 따르지 말라고 안내합니다.
- **전송:** 기억 목록은 채팅마다 Claude API 로 함께 나갑니다(공지로 처리하는 기존 정책과 같음).

## 대화 내용 전달과의 관계
- "엄마"처럼 부르는 사람은 이 기능에 저장하지 않습니다. 이미 있는 가족 관계(`family_relation`, 엄마·아빠 등)와 별명(`member_nicknames`)으로 찾고, 대화 내용 전달 기능에서 다룹니다.

## 완료 조건
- 다음 대화에서 기억을 씁니다(실제 Claude 확인 1회).
- 다른 사람의 기억은 도구·API 어디서도 읽거나 지울 수 없습니다.
- 가족방 `@가비` 요청에는 기억이 들어가지 않습니다.
- 격리 PostgreSQL 에서 마이그레이션 올리기·스키마 일치 검증.
- 서버·앱 시험, 린트.

## 미정
- 내용 칸 암호화: 첫 버전은 하지 않는다(사용자 진행 결정, 2026-11-09). 하려면 `cryptography` 의존성과 키 관리가 필요합니다.
- 구성원이 가족을 나갈 때 기억도 지울지.
- 개인정보처리방침에 "기억하라고 한 내용을 서버에 저장한다" 문구 추가(사용자 작업).
