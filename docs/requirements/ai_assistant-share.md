# 기능: 대화 내용 전달

## 목적
AI 채팅에서 "이 내용 엄마한테도 알려줘", "가족방에 올려줘"라고 하면 가비가 요약을 만들고, 사용자가 확인한 뒤에만 소통 채팅으로 보냅니다.
올린 문서 내용이든 그냥 나눈 대화든 같은 흐름입니다.

## 화면
- 새 화면은 없습니다. 답 아래에 기존 확인 카드가 뜹니다: "김○○(엄마)에게 보낼까요?"와 보낼 글, [확인] [취소].
- 글을 고치려면 채팅으로 "이렇게 바꿔줘"라고 말합니다. 새 카드가 만들어집니다.
- 받는 사람이 여럿이면 가비가 먼저 누구인지 물어봅니다.

## 보내는 곳
- 사람을 말하면 그 사람과의 1:1 방(없으면 만듭니다). 여러 명을 말하면 사람마다 카드가 하나씩 뜹니다(한 답변에 최대 3개).
- "가족방", "다 같이"면 가족 전체방.
- 메시지는 **보낸 사람 이름**으로 올라가고 끝에 "(가비가 정리해 줬어요)"가 붙습니다.

## 받는 사람 찾기 (서버 코드가 합니다)
1. 내가 붙인 별명(`member_nicknames`)
2. 가족 안 표시 이름, 이름, 성을 뗀 이름
3. 가족 관계(`family_relation`: 엄마·아빠·아들·딸·할머니·할아버지, 기타는 직접 적은 관계)

앞 단계에서 찾으면 그 결과를 씁니다. 후보가 여럿이면 카드를 만들지 않고 후보를 돌려줘 가비가 물어봅니다. 호칭을 새로 저장하지는 않습니다.

## API
- 메인 채팅 도구: `prepare_share(to, text, member_id?)`. 카드를 만들 뿐 보내지 않습니다.
- `POST /ai-assistant/agent/confirm` `{ token }`: 사용자가 확인했을 때 실행합니다. 토큰은 서버 서명, 10분, 한 번만, 이 사용자·이 가족만.
- `ProposalOut.tab` 에 `ai-assistant` 추가(앱 호환).

## 데이터
- 새 표 없음. 보낸 글은 일반 소통 메시지로 저장됩니다. AI 대화 원문은 계속 폰에만 있습니다.

## 규칙
- AI 채팅 탭에서만, 가족 AI 동의가 켜져 있을 때만 씁니다.
- 사용자가 이번 대화에서 직접 요청했을 때만 만듭니다. 문서, 웹 페이지, 가족 대화 속 지시로는 만들지 않습니다.
- 요청한 내용만 담습니다. 같은 대화의 다른 얘기, 고민은 넣지 않습니다. 프롬프트 지시라 코드로 보장되지는 않아 카드로 확인받습니다.
- 주민번호·카드·계좌·비밀번호가 있으면 코드가 거절합니다. 글은 500자까지입니다.
- 앞 대화 10개 안에 대상이 안 보이면 추측하지 않고 어떤 내용인지 물어봅니다.

## 완료 조건
- 확인 전에는 아무것도 보내지지 않습니다. 토큰 재사용은 409, 남의 토큰은 거절합니다.
- 동명이인·후보 여럿·없는 사람에서 잘못 보내지 않습니다.
- 가족을 나간 사람에게 보내지 않습니다.
- 가족방 `@가비` 요청에는 도구가 없습니다.
- 서버·앱 시험, 실제 Claude 확인 1회.

## 미정
- 카드 안에서 글을 바로 고치는 기능.
- 사진·파일 원본 함께 보내기.
- 예전 대화(앞 10개 밖) 찾아오기.
