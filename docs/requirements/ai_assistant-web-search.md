# 기능: AI 채팅 웹 검색

## 목적
AI 채팅 탭에서 날씨, 뉴스, 가격, 제도처럼 최신이거나 바깥 세상의 정보를 물으면 가비가 웹을 찾아 출처와 함께 답한다.
가족 문서·일정·지출·가족 대화는 지금처럼 우리 도구로 찾는다.

## 화면
- 새 화면은 없다. 웹을 근거로 답하면 답 아래에 "웹에서 찾았어요" 카드가 펼쳐진 채로 보인다(눈에 잘 띄어야 한다, 사용자 요청 2026-11-09).
- 카드의 제목을 누르면 브라우저로 그 페이지가 열린다.

## API
- `POST /ai-assistant/chat` 응답에 `web_sources: [{ title, url }]` 를 추가한다(추가만이라 하위 호환).
- 검색은 Anthropic 서버 도구 `web_search_20250305` 를 쓴다. 서버가 직접 웹에 접속하지 않는다.
- 어떤 도구를 쓸지는 Claude 가 판단하고, 기준은 시스템 프롬프트로 정한다. Jev 같은 분류 단계는 두지 않는다.

## 데이터
- 새 표·칸 없음. 검색어와 결과를 저장하지 않는다.

## 범위
- AI 채팅 탭(`audience=me`)만. 가족방 `@가비`(방 대화가 검색어로 나갈 수 있다), 탭 에이전트, `/ai-assistant/knowledge/ask` 는 제외한다.
- `WEB_SEARCH_ENABLED`(기본 false)로 켠다. 질문당 검색은 `WEB_SEARCH_MAX_USES`(기본 3)번까지다.

## 완료 조건
- 켜져 있고 AI 채팅 탭일 때만 도구가 요청에 들어간다.
- 프롬프트가 검색어에 가족 이름·연락처·주소·문서 내용을 넣지 말라고 지시한다. 모델 지시라 코드로 보장되지는 않는다.
- 웹 페이지 속 지시문을 따르지 않도록 프롬프트에 넣는다.
- 답의 인용(`web_search_result_location`)만 출처로 돌려주고, 같은 주소는 하나로 합치고, http(s) 주소만 쓴다.
- 검색이 길어져 온 `pause_turn` 은 답이 끝난 것으로 보지 않고, `MAX_STEPS` 안에서 이어서 부른다.
- 가짜 응답 시험과 실제 Claude 호출 확인 1회.

## 비용
- 검색 1,000회에 10달러 + 결과만큼의 입력 토큰. 검색 횟수는 `ai_usage_logs` 와 하루 한도에 따로 세지 않는다.
- 최악의 경우 사용자 하루 100회 × 3번 = 300번, 약 3달러(토큰 별도).

## 미정
- 개인정보처리방침·Play 데이터 안전 양식에 "질문이 웹 검색에 쓰일 수 있다"는 문구 추가(사용자 작업).
- 검색 횟수를 한도에 따로 셀지.
