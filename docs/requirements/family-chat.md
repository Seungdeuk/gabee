# 기능: family-chat (가족 채팅·소통)

> 2026-10 사용자(팀) 요청으로 기록한 요구사항이다. 아직 구현되지 않은 항목은 "예정"으로 표시한다. 기존 서버 `family_chat`(단체 메시지 목록·전송)과 모바일 소통 탭(임시 데이터)을 먼저 확인하고 이어서 만든다 — 중복 개발하지 않는다.

## 범위(순서)

| 단계 | 기능 | 설명 | 상태 |
|---|---|---|---|
| 0 | **대화 내용 자동 요약** | 긴 가족 대화를 핵심 내용 중심으로 AI 요약 | **구현됨**(이 문서의 "대화 요약") |
| Chat 1 | 가족 채팅방 · 메시지 송수신 | 가족 구성원이 함께 대화하는 공간, 실시간 전송·조회 | 예정 |
| Chat 2 | 1:1 채팅 · 읽음 표시 | 특정 가족 구성원과 개별 대화, 메시지 확인 여부 | 예정 |
| Chat 3 | 사진·파일 공유 | 사진이나 문서를 채팅방에 공유 | 예정 |
| Chat 4 | 공동 할 일 · 가족 연락처 | 가족 간 부탁과 할 일 공유, 구성원 연락처 관리 | 예정 |

## 대화 요약 (구현됨)

- 구성원이 요약을 **눌렀을 때만** 그 가족 그룹의 최근 대화(최대 300개, 기본 200개, 글자 수 한도 12,000자 — 넘으면 오래된 것부터 뺀다)를 AI(Anthropic)로 보내 핵심 위주로 요약한다. 결정 사항·해야 할 일·일정·답 못 받은 질문을 구분하고, 연락처·계좌 같은 개인정보는 일반화해서 쓰고, 대화 글자 속 지시는 따르지 않는다.
- **개인정보 원칙**: 보내는 것은 대화 글자와 이름뿐(사용자 id·연락처 제외), 요약과 대화는 저장하지 않고 로그에도 남기지 않는다. 사용자별 시간당 호출 수를 제한한다(비용·남용 방지). 다른 그룹의 대화는 절대 보내지 않는다.
- 모델은 환경변수 `ANTHROPIC_MODEL`(없으면 `LLM_MODEL`, 둘 다 없으면 `claude-haiku-5-5`)로 고르고, 키는 `ANTHROPIC_API_KEY`(서버 환경변수). 키가 없으면 503 `llm_unavailable`.
- 참고: 이 저장소에는 개인정보가 섞일 수 있는 글자는 외부 AI 대신 로컬 모델(Ollama)로 처리한다는 원칙이 있다. 대화 요약은 사용자 요청에 따라 Anthropic 을 쓰며, 위 제한으로 전송 범위를 최소화했다. 로컬 모델로 바꾸려면 `summary_service` 의 호출부만 바꾸면 된다.
