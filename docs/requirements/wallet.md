# 기능: 지갑

> 상태: **초안** (2026-11-02). 팀 회의 결과로 하단 탭 "돌봄"을 "지갑"으로 바꾸고, 데일리 체크를 빼고 정산·용돈만 남기기로 했다. 서버 구현은 기존 가계(`billing`) 기능을 그대로 쓰므로 이 문서는 지갑 탭의 범위와 화면, 정하지 않은 것을 적는다. 합의되지 않은 항목은 "미정"에 두고 임의로 정하지 않는다.

## 목적
가족이 함께 쓴 돈을 **정산**하고, 아이의 **용돈**을 앱 안 장부로 챙긴다. 지출을 넣고(지출), 대상 태그를 걸어 정산하고(정산하기), 아이 용돈 주기·지급·사용·요청을 관리한다(용돈).

## 용어
- **지갑 탭**: 하단 탭. 이름은 "지갑", 아이콘은 지갑 모양(`wallet-outline`). 라우트 이름은 `care`로 그대로 둔다(딥링크와 기존 참조를 건드리지 않기 위해).
- **정산하기**: 정산하는 사람이 지출을 고르고 대상 태그(부모님·자녀·가족 전체, 또는 직접 고르기)를 걸어 정산하는 동작. 정산 전 지출은 잔액에 들어가지 않는다.
- **용돈 장부**: 은행·계좌와 연결하지 않고 앱 안에서만 남은 용돈을 기록한다. 실제 송금은 직접 한다.
- **돌봄(닫힌 것)**: 데일리 체크, 현황판, 추천·식단, 위치, 돌봄 에이전트. 이번 범위에서 뺐다.

## 합의된 것
- 지갑 탭에는 **정산 / 지출 / 용돈**만 둔다. 위쪽에 월 선택기를 둔다.
- **월말 정산 알림은 그대로 둔다.** 정산 담당자에게 "정산 안 한 지출 N건 · 월말까지 N일"과 [정산하기] 버튼을 보여 주고, 버튼을 누르면 정산 구역으로 돌아간다(담당자에게만 보임, 서버가 `show`를 정함).
- **구독 기능은 제외한다.** 공동구독 구역, 결제일 알림, 정산 요약 카드는 화면에서 뺐고, 정산 에이전트의 구독 도구(`list_subscriptions`, `get_upcoming_payments`)도 주석 처리했다. 메인 AI는 구독·통신비·결제일 질문에 확인할 수 없다고 답한다.
- 다음은 **삭제하지 않고 주석 처리**했다(다시 켤 때 되돌린다): 현황판(데일리 체크)·공동구독·위치 구역, 결제일 알림 배너, 정산 요약 카드, 서버 주소가 없을 때 보이던 돌봄 임시 화면(`CarePreview`), 정산 에이전트의 구독 도구 2개.
- **돌봄 서버 API(`/care/*`)를 닫았다.** 스위치 `CARE_API_ENABLED`(기본 꺼짐)가 꺼져 있으면 403 `care_disabled`. 위치 동의 철회·조회(`/care/location/consent`)는 저장된 내 위치를 지우는 길이라 열어 둔다. 위치 기능 자체는 기존대로 `CARE_LOCATION_ENABLED` 꺼짐이다.
- **메인 AI 에이전트에서 돌봄 에이전트(`ask_care`)를 뺐다.** 정산 에이전트(`ask_billing`)는 남는다. 돌봄 항목을 물으면 AI는 확인할 수 없다고 답한다.
- 돌봄 재설계(개인별 현황판, 지난 항목, 자정 마감)와 안부 기능은 이번 범위에서 접었다. 프로토타입과 초안은 보관만 한다.

## 화면
- 지갑 탭: 월 선택기 → 월말 정산 알림(정산 담당자에게만, 있을 때만) → **정산 / 지출 / 용돈** 구역(`MoneySection`).
  - 정산: 지출 선택 → 고정 태그 3개(부모님·자녀·가족 전체) → 나눌 사람 → 정산하기, 구성원별 잔액과 최소 송금 목록, 송금 완료 표시와 취소, 정산 담당자 표시와 변경.
  - 지출: "+ 지출 추가"(항목·금액), 내역 5개씩 더보기, 삭제. 지출에는 "미정산"·정산 태그 표시가 붙는다.
  - 용돈: 자녀별 잔액·받은 돈·쓴 돈·내역, 고정 주기(자동/리마인드), 수동 지급·사용 기록·취소, 자녀 본인의 용돈 요청과 부모의 승인·거절.
- 화면에서 뺀 것(코드는 있음): 현황판, 공동구독, 위치, 결제일 알림 배너, 정산 요약 카드.
- 서버 주소(`EXPO_PUBLIC_API_URL`)가 없을 때의 임시 데이터 화면은 지갑 탭에서 보이지 않는다.

## API
- 지갑 탭은 기존 `/billing/*`를 그대로 쓴다. 새 엔드포인트는 없다.
  - 지출: `GET·POST /billing/expenses`, `DELETE /billing/expenses/{id}`, `GET /billing/summary`
  - 정산: `GET /billing/settlement`, `GET /billing/settlement/tags`, `POST /billing/settlement/tag`, `GET·PUT /billing/settlement/manager`, `PUT /billing/settlement/minors`, `POST /billing/settlement/payments`, `DELETE /billing/settlement/payments/{id}`
  - 용돈: `GET /billing/allowances`, `PUT·DELETE …/{child_id}/plan`, `POST …/plan/pay`, `POST …/credits`, `POST …/uses`, `POST …/requests`(+ approve·reject·취소), `DELETE …/entries/{id}`
  - 에이전트: `POST /billing/agent/chat`, `POST /billing/agent/confirm`
  - 월말 정산 알림: `GET /billing/settlement/reminder` (화면에서 쓴다)
- 화면에서 쓰지 않지만 서버에 남은 것: 구독·통신비(`/billing/subscriptions/*`). 닫을지는 미정이다.
- 돌봄 서버 API(`/care/*`, `/care/agent/*`)는 닫혀 있다(위 "합의된 것"). 닫힌 응답은 403 `care_disabled`.
- 권한은 `docs/contracts/permissions.md`와 기존 가계 규칙을 따른다(용돈 주기·지급은 부모 역할 또는 그룹을 만든 사람 등, 자세한 것은 `docs/features/billing.md`).

## 데이터
- 지갑 개편으로 바꾼 테이블·컬럼은 없다. 가계 테이블(`expenses`, 정산 설정, 용돈 장부 등)은 그대로다.
- 돌봄 테이블(`care_items`, `care_entries`, `care_records`, 식단·위치)은 지우지 않고 그대로 둔다. 닫은 API가 쓰지 않을 뿐이다.
- 지우는 변경은 하지 않았다. 지우려면 PR에 적고 DB 담당자 승인을 받는다.

## 완료 조건
- 지갑 탭에 정산·지출·용돈과 월말 정산 알림(담당자에게만)이 보이고, 현황판·공동구독·위치·결제일 알림·정산 요약이 보이지 않는다(앱 테스트와 실기기에서 확인).
- 정산 에이전트에 구독 도구가 없다(서버 테스트).
- 돌봄 서버 API가 닫혀 있다: 닫힌 상태에서 `/care/*`는 403 `care_disabled`, 위치 동의 철회·조회는 200(서버 테스트 `test_care_api_closed.py`).
- 메인 에이전트의 도구에 `ask_care`가 없고 `ask_billing`은 있다(서버 테스트).
- 서버·앱 테스트와 린트를 통과한다. `release/1.2`가 원래 안고 있는 실패(가입 승인, CI 워크플로우 확인)는 이 변경과 무관하다.

## 미정
다음은 임의로 정하지 않고 확인한다.
- **구독 서버 API**: 구독 기능은 화면과 에이전트에서 뺐다. 서버의 `/billing/subscriptions/*`를 닫을지 유지할지. 일정 탭의 추천(`schedule/agent/suggest_sources.py`)이 구독 데이터를 참고하므로 닫기 전에 일정 담당과 확인이 필요하다.
- **정산 요약 카드**: 현황판이 없어져서 갈 곳이 없다. 지갑에 다시 둘지.
- **지출의 포함 여부**: "정산하기와 용돈만"이라고 했지만 정산에는 지출 입력이 필요해서 지출을 같이 두었다. 맞는지 확인이 필요하다.
- **돌봄 서버 코드**: 닫은 `/care/*`를 나중에 삭제할지 유지할지. 위치 동의 철회 경로를 언제까지 열어 둘지.
- **메인 AI**: 돌봄 항목 질문에 "확인할 수 없다"고 답하는 것으로 충분한지. 평가 데이터(`evals/tab_agents/cases.json`)의 돌봄 사례 4개를 어떻게 할지.
- **용돈 요청과 아이 계정**: 자녀 본인이 요청하는 기능이 있어 아이 계정이 전제다. 만 14세 미만 개인정보 처리는 확인하지 못했다(법적 확인 미완).
- **푸시 알림**: 월말 정산, 용돈 리마인드는 앱 안 배너뿐이다. 푸시는 인프라(스케줄러·푸시)가 생기면 다시 본다.
- **탭 라우트 이름**: `care`를 `wallet`으로 바꿀지(바꾸면 딥링크 영향 확인 필요).
- **탭 순서·아이콘**: 지갑 아이콘이 팀 디자인과 맞는지.
