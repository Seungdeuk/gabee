# 기능: 메타 광고 성과 (관리자 › 데이터 분석)

> 상태: 초안 (2026-11-24, kang). 서버 읽기 전용 조회 + 관리자 화면 표.

## 목적
페이스북·인스타그램 광고에 돈을 얼마 썼고, 몇 명이 봤고(노출), 눌렀고(클릭), 설치·가입했는지를 메타 광고 관리자에 따로 들어가지 않고 가비 관리자 페이지에서 본다.
설치·가입 숫자는 앱의 메타 SDK(`docs/features/meta-sdk.md`)가 보낸 이벤트를 메타가 광고에 연결한 값이다.

## 흐름
1. 관리자가 데이터 분석 탭을 열면 화면이 `GET /admin/service/meta-ads?days=7` 을 따로 부른다(다른 화면 열기를 늦추지 않게).
2. 서버가 메타 마케팅 API `GET /{버전}/act_{광고 계정}/insights` 를 캠페인 단위(`level=campaign`)로 부른다. 기간은 `last_7d`·`last_30d`.
3. 받은 값을 캠페인별로 정리하고 합계를 더해 돌려준다. 성공은 10분, 실패는 1분 캐시한다.

## 화면
- "유입 경로" 표 아래 "메타 광고 성과 (페이스북·인스타그램)" 구역. 오른쪽 위 "최근 7일 / 최근 30일" 버튼.
- 합계 칸: 광고비, 노출, 클릭(클릭률), 설치(설치당 광고비), 가입(가입당 광고비).
- 캠페인 표: 캠페인 / 광고비 / 노출 / 클릭 / 설치 / 가입. 광고비 많은 순.
- 토큰이 없으면 "설정 전" 문장, 메타 오류면 이유 한 줄(토큰 만료·권한 없음·요청 한도·계정 번호). 가짜 숫자는 보이지 않는다.

## API
- `GET /admin/service/meta-ads?days=7|30` (통합관리자만, `require_operator("admin")`). 그 밖의 days 는 422.
- 응답: `configured`, `ok`, `reason`, `days`, `currency`, `total{spend, impressions, clicks, installs, signups}`, `campaigns[{campaign_id, name, ...같은 숫자}]`, `fetched_at`.
- 메타 오류·연결 실패도 200 + `ok=false` + `reason`(관리자 화면이 깨지지 않게).
- 설치는 메타 action_type `mobile_app_install`, 가입은 `app_custom_event.fb_mobile_complete_registration`.

## 설정 (서버 환경변수, 시크릿)
- `META_ADS_ACCESS_TOKEN`: 메타 비즈니스 설정 › 사용자 › 시스템 사용자에서 `ads_read` 권한으로 만든 토큰. 코드·Git·로그·채팅에 쓰지 않는다.
- `META_ADS_ACCOUNT_ID`: 광고 계정 번호(숫자 또는 `act_숫자`). 숫자가 아니면 메타를 부르지 않는다.
- `META_ADS_API_VERSION`: 기본 `v25.0`(2026-11-24 메타 문서 기준 마케팅 API 사용 가능 버전). 만료 공지가 오면 바꾼다.

## 개인정보
- 메타로 보내는 것: 광고 계정 번호, 기간, 받을 칸 이름뿐. 회원·가족 데이터는 보내지 않는다.
- 토큰은 `Authorization` 머리줄로만 보낸다(주소에 넣지 않아 접속 기록에 남지 않는다). 메타의 오류 원문은 화면에 싣지 않는다.

## 완료 조건
- 서버 시험(`service_admin/tests/test_meta_ads.py`): 비로그인 401, 관리자 아님 403, 설정 없음은 메타를 부르지 않고 configured=false, 잘못된 계정 번호는 보내지 않음, 캠페인 합계·정렬·요청 모양(토큰은 머리줄), 다음 쪽 따라가기, 메타 오류 코드별 이유(토큰이 응답에 없음), 연결 실패, 캐시, days 422.
- 보안 시험 표에 새 주소와 새 외부 호출 파일을 올린다.
